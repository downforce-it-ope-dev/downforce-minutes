# SET-03 문서 서비스 선택

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-03 |
| 유형 | 페이지 (마법사 1단계) |
| 경로 | `/setup/document` (최초 연결), `/settings/document` (변경 모드) |
| 현재 구현 | `frontend/src/DocumentSetupWizard.tsx` (서비스 미선택 상태) |
| 진입 조건 | 로그인(신규). 문서 연결이 없어 CMN-04에서 이동, SET-02 "문서 서비스 변경", HOME-01-P01 "문서 연결 변경" |
| 연결 화면 | 서비스 선택 → SET-04 / 문서 서비스 설정으로 돌아가기 → SET-02 (연결 있을 때) |
| 사용 API | API-023 문서 설정 상태 |
| 현행 캡처 | [문서 서비스 연결](<../현_UI/문서 서비스 연결.png>) (최초), [문서 연결 변경](<../현_UI/문서 연결 변경.png>) (변경) |

## 1. 화면 개요

회의록을 저장할 문서 서비스(Notion 또는 Confluence Cloud)를 고른다. 처음 연결할 때와 바꿀 때 같은 화면을 쓴다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-03-F01 | 서비스 선택 | Notion / Confluence | 선택 시 SET-04로 진행, 이전 입력 초기화 |
| SET-03-F02 | 현재 연결 안내 | 변경 모드일 때 | "현재 {서비스}에 연결되어 있습니다. 변경할 문서 서비스를 선택해 주세요." |
| SET-03-F03 | 현재 연결 요약 | 연결이 있을 때 | 현행: "문서 서비스 / 현재 연결: … / 연결 버전: n" 카드 |
| SET-03-F04 | 돌아가기 | 변경 취소 | 문서 서비스 설정으로 돌아가기 → SET-02 |
| SET-03-F05 | 진행 중 작업 우선 | 진행·실패 작업이 있으면 | 선택 대신 SET-05 표시 |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4·8장을 따른다.

- **집중 모드**: 문서 연결 마법사(SET-03~SET-06)는 CMN-01 "집중 모드"로 표시한다. 내비게이션 레일·하단 탭 바를 숨기고 상단 바에는 제목만 둔다. 현행도 `/setup/document`, `/settings/document`에서 하단 탭 바를 숨긴다(CMN-01-F03).

### 3.1 단계 표시 (제안)

마법사 상단에 `① 서비스 선택 → ② 연결 정보 → ③ 문서 생성` 단계 표시를 둔다. 변경 모드는 `③ 자료 이전 → ④ 전환`까지 표시한다.

- 태블릿: 단계 이름을 모두 가로로 나열한다. 완료 단계는 ✓, 현재 단계는 `primary` 색 + 굵기로 강조한다. 색만으로 구분하지 않는다.
- 휴대폰: 폭이 좁아 "1/3 서비스 선택"처럼 현재 단계 번호와 이름만 표시한다(제안).
- 단계 표시는 누르는 대상이 아니다(표시 전용).
- **확인 필요** — 단계 표시기 높이·점 크기는 8장에 정의가 없다. 제안: 글자 `label`, 단계 점 24, 전체 높이 48.

### 3.2 태블릿 (기준, 600px 이상)

메뉴 없이 가운데 1단 배치를 쓴다.

```
┌──────────────────────────────────────────────────────────────┐
│ 문서 서비스 연결                                                │  상단 바 64px (제목만)
├──────────────────────────────────────────────────────────────┤
│         ① 서비스 선택 ● ─ ② 연결 정보 ─ ③ 문서 생성               │  단계 표시
│                                                              │
│         연결된 문서 서비스가 없습니다.                              │
│         회의록을 저장하려면 먼저 서비스를 연결해 주세요.               │
│                                                              │
│         ┌──────────────────────────────────────────┐         │
│         │ (N)  Notion                          →  │         │  선택 카드 (2줄 행 76 이상)
│         │      Notion 페이지에 회의록을 저장합니다    │         │
│         └──────────────────────────────────────────┘         │
│         ┌──────────────────────────────────────────┐         │
│         │ (C)  Confluence Cloud                →  │         │
│         │      Confluence Space에 회의록을 저장합니다  │         │
│         └──────────────────────────────────────────┘         │
│                                                              │
│         ← 문서 서비스 설정으로 돌아가기                             │
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 바 (64px) | 제목 | 제목(h1) | 최초: 문서 서비스 연결 / 변경: 문서 서비스 선택. `headline` |
| 머리 | 설명 | 텍스트 | 최초: "연결된 문서 서비스가 없습니다. 회의록을 저장하려면 먼저 서비스를 연결해 주세요." `body`, `text-muted` |
| | 단계 표시 | 단계 표시기 | **제안** (3.1) |
| | 현재 연결 요약 | 안내 상자 | 변경 모드일 때(F02·F03). `primary-soft` |
| 선택 | 서비스 카드 ×2 | 선택 카드(버튼) | 아이콘, 이름, 설명("Notion에 연결"), → 화살표. **제안**: 설명을 "Notion 페이지에 회의록을 저장합니다"처럼 구체화, 현재 연결된 서비스에 "현재 사용 중" 배지(`selected` 계열 배지 + 문구). 카드 전체가 누르는 영역, 높이는 2줄 목록 행 기준 이상(태블릿 76, 휴대폰 72), 테두리 `border`, `radius-lg`, 카드 사이 12 |
| 하단 | 문서 서비스 설정으로 돌아가기 | 링크 | 연결이 있을 때만. 누르는 영역 높이 48 |
| 배치 | 본문 폭 | - | **확인 필요** — 마법사 가운데 열 최대 폭은 8장에 정의가 없다. 제안: 640px(입력 폼 SET-04와 같게) |

### 3.3 태블릿 가로 (960px 이상)

세로 배치를 그대로 쓰고 가운데 정렬한다. 본문 최대 폭 1040px 안에서 마법사 열 폭은 3.2와 같다.

### 3.4 휴대폰 (600px 미만)

- 1단, 좌우 여백 16px. 상단 바 56px(제목만), 하단 탭 바 없음(집중 모드).
- 단계 표시는 "1/3 서비스 선택" 형태(3.1).
- 서비스 카드는 폭 가득, 높이 72 이상.
- 이 단계는 카드를 누르는 것이 곧 다음 단계 이동이라 하단 고정 주 버튼을 두지 않는다. "문서 서비스 설정으로 돌아가기"는 목록 아래 링크로 두고, 화면 하단 안전 영역만큼 띄운다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 불러오는 중 | "문서 설정을 불러오는 중…" |
| 조회 실패 | "문서 연결 상태를 확인할 수 없습니다" + 다시 불러오기 |
| 저장소 사용 불가 | SET-02와 같은 안내 |
| 최초 연결 | 서비스 카드 2개 |
| 변경 모드 | 안내 문구 + 현재 연결 요약 + 서비스 카드 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 변경 화면 캡처에서 이전 연결 완료 카드(단계 표시와 "확인" 버튼)가 서비스 선택 위에 그대로 남아 있다. 코드상 마지막 초기화 작업(`INITIALIZE`, `SUCCEEDED`)이 문서 설정 상태에 남아 있으면 완료 카드를 계속 그리는 조건으로 보인다(추정, 실제 재현 확인 필요). 리뉴얼 시 단계별 표시 조건과 상태 초기화 규칙을 명확히 해야 한다.
- **제안** — 마법사 단계 표시, 서비스별 특징(필요 정보, 권한) 짧은 비교.
- **확인 필요** — HOME-01-P01의 "문서 연결 변경"이 `/setup/document`(이 화면, 비설정 모드)로 이동하는데, 코드상 이 경로에서는 연결 있는 상태의 변경이 끝까지 진행되지 않는 것으로 보인다(추정). 변경 진입점을 SET-02로 통일할지 결정한다. 단계 표시기 크기와 마법사 열 폭(3장). 화면 크기 기준은 D-06(태블릿 기준)으로 결정됨.
