# MTG-05 회의 결과

| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-05 |
| 유형 | 페이지 |
| 경로 | `/meetings/:sessionId/complete` |
| 현재 구현 | `frontend/src/CompletePage.tsx` |
| 진입 조건 | MTG-04에서 발송 |
| 연결 화면 | 저장된 회의록 보기 → MIN-02 |
| 사용 API | API-010 저장·전달 상태(반복 조회), API-001 앱 설정, API-003 참석자, API-015 문서 저장·전달 시작/재시도, API-016 전달 재시도 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

회의록이 문서 서비스에 저장되고 이메일·Slack으로 전달되는 과정을 단계별로 보여 준다. 실패한 전달은 항목별로 다시 보낼 수 있다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MTG-05-F01 | 결과 제목 | 전체 상태 요약 | 문서 저장 실패 / 회의록 저장 중 / 회의록 저장 준비 중 / 일부 전달 실패 / 전달 진행 중 / 완료 / 문서 저장 완료 |
| MTG-05-F02 | 단계 표시 | 회의록 저장 → 이메일 전달 → Slack 전달 → 완료 | 이메일·Slack 단계는 전달 건이 있을 때만. 단계별 상태(완료·진행 중·실패·대기), 설명, 다음 조치, 오류 코드 |
| MTG-05-F03 | 자동 저장 시작 | 검토 확정만 되고 저장이 시작되지 않은 경우 | 화면 진입 시 자동으로 저장·전달 요청 |
| MTG-05-F04 | 자동 갱신 | 진행 중이면 1.5초마다 조회 | 완료·실패 시 중지 |
| MTG-05-F05 | 이메일 결과 | 수신자별 상태 | 이름, 이메일, 상태(전달 완료·진행 중·실패), 실패 시 재전송 |
| MTG-05-F06 | Slack 결과 | 알림 상태 | 상태, 실패 원인·오류 코드, 재시도 |
| MTG-05-F07 | 항목 재전송 | 실패한 전달 1건 재시도 | 재시도 가능 + (이메일은 이메일 설정 완료) 조건. 같은 클릭은 같은 멱등 키 |
| MTG-05-F08 | 저장·전달 재시도 | 문서 저장 실패 시 전체 재시도 | 서버 허용 시 |
| MTG-05-F09 | 저장된 회의록 보기 | MIN-02 이동 | 저장·전달이 모두 완료됐을 때만 |
| MTG-05-F10 | 상태 새로고침 | 수동 조회 | - |

## 3. 화면 구성 요소

```
┌ 상단 바: 회의 결과 ─────────────────────────────────────┐
│   ✓ 완료                                              │
│   주간 회의 · 2026년 11월 5일 (제안)                      │
│                                                      │
│   ✓ 회의록 저장   회의록 문서가 저장되었습니다.              │
│   ✓ 이메일 전달   전달이 완료되었습니다.                    │
│   ✕ Slack 전달   1건의 전달에 실패했습니다.  오류 코드: …    │
│   ● 완료        일부 전달에 실패했습니다.                   │
│                                                      │
│   이메일                                               │
│   홍길동  hong@…    전달 완료                            │
│   김철수  kim@…     전달 실패            [재전송]          │
│   Slack 알림       전달 실패            [재시도]          │
│                                                      │
│   [저장된 회의록 보기]  [상태 새로고침]                      │
└──────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 요약 | 결과 제목 | 제목 + 상태 아이콘 | F01 |
| | 회의 정보 | 텍스트 | **제안**: 회의 제목·날짜 |
| 진행 단계 | 단계 목록 | 단계 표시기 | 단계명, 상태 라벨, 설명, "다음 조치: …", "오류 코드: …" |
| 이메일 | 수신자 행 | 목록 | 이름, 이메일, 상태, 재전송 버튼(실패 + 재시도 가능) |
| Slack | 알림 행 | 목록 | 상태, 실패 원인, 오류 코드, 재시도 버튼 |
| 메시지 | 오류·진행 문구 | 텍스트 | 요청 실패 사유, 진행 안내 |
| 실행 | 저장된 회의록 보기 | 주 버튼 | 모두 완료 시 |
| | 문서 저장 재시도 / 저장 및 전달 재시도 | 주 버튼 | 허용 시 |
| | 상태 새로고침 | 보조 버튼 | 항상 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 로딩 | "회의 결과를 불러오는 중…" |
| 조회 실패 | 오류 카드 + 다시 시도 ("회의를 찾을 수 없습니다." 포함) |
| 저장 중 | 회의록 저장 단계 진행 중 |
| 저장 실패 | 오류 코드별 원인 + 다음 조치 + 문서 저장 재시도 |
| 전달 중 | 이메일·Slack 단계 진행 중, 자동 갱신 |
| 일부 실패 | 실패 행에 재전송·재시도 |
| 완료 | 모든 단계 완료 + 저장된 회의록 보기 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 오류 코드와 기술 문구가 사용자에게 그대로 노출된다. "Retry", "Slack 전달", "Email" 등 영문·한글 혼용. 완료 후 다음 행동(목록으로, 새 회의)이 약하다.
- **제안**
  - 성공 시 큰 완료 표시 + 저장된 회의록 보기 / 새 회의 시작 / 회의록 목록
  - 오류 코드는 접힌 "자세히" 영역으로 이동
  - 저장된 문서(Notion·Confluence) 원문 바로 열기 링크 — 응답에 문서 URL이 있는지 확인 필요
- **확인 필요** — D-07(발송 대상 선택을 MTG-04에서 할 경우 이 화면의 표시 범위)
