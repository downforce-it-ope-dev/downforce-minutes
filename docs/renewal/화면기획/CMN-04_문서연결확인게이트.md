# CMN-04 문서 연결 확인 (진입 점검)

| 항목 | 내용 |
|---|---|
| 화면 ID | CMN-04 |
| 유형 | 진입 점검 (로딩·오류 화면) |
| 경로 | `/`, `/meetings/new`, `/participants`, `/settings/participants` 진입 시 |
| 현재 구현 | `frontend/src/App.tsx` `SetupGate` |
| 진입 조건 | 로그인 완료 후 (신규) |
| 연결 화면 | 통과 → 요청 화면 / 미연결 → SET-03 / 저장소 문제 → SET-02 경로 |
| 사용 API | API-023 문서 설정 상태 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

회의 생성처럼 문서 서비스가 필요한 화면에 들어가기 전에 문서 연결이 준비됐는지 확인한다. 준비되지 않았으면 문서 연결 화면으로 보낸다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| CMN-04-F01 | 연결 확인 | 문서 설정 상태 조회 | `status = READY` 이고 `canCreateMeeting = true`이면 통과 |
| CMN-04-F02 | 미연결 이동 | 연결이 없거나 준비되지 않음 | `/setup/document`(SET-03)로 교체 이동, 원래 경로를 전달 |
| CMN-04-F03 | 저장소 문제 이동 | `STORAGE_UNAVAILABLE` | `/settings/document`로 이동 |
| CMN-04-F04 | 확인 실패 처리 | 조회 실패 | 오류 카드 + 다시 확인 / 문서 연결 설정 |

## 3. 화면 구성 요소

화면 기준은 마이크가 있는 태블릿이다. PC 전용 배치는 만들지 않는다(D-06). 공통 틀은 [CMN-01](CMN-01_공통레이아웃.md) 3장, 크기·글자·컴포넌트 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 8장을 따른다.

### 3.1 태블릿 (기준, 폭 600px 이상)

점검은 요청한 화면의 본문 자리에서 진행한다. 공통 레이아웃(레일·상단 바)을 함께 보일지는 **확인 필요**이며, 아래는 함께 보이는 경우의 실패 상태 배치다.

```
┌──────┬──────────────────────────────────────────────┐
│ [로고]│ (요청한 화면 제목)                               │  상단 바 64px
│      ├──────────────────────────────────────────────┤
│  ⌂   │                                              │
│  홈   │      ┌──────────────────────────────────┐    │
│  ▤   │      │ ⚠ 문서 연결 상태를 확인할 수 없습니다  │    │  title
│ 회의록 │      │   서버 연결을 확인한 뒤 다시 시도하거나 │    │  body
│  👥  │      │   문서 연결 설정을 열어 주세요.        │    │
│ 참석자 │      │                                  │    │
│  ⚙   │      │  [ 문서 연결 설정 ]  [  다시 확인  ]  │    │  lg 56
│  설정  │      └──────────────────────────────────┘    │
│      │                                              │
│  [👤] │                                              │
└──────┴──────────────────────────────────────────────┘
 레일 88px, 오류 카드는 본문 가운데 정렬
```

| 상태 | 요소 | 내용 |
|---|---|---|
| 확인 중 | 상태 문구 | 문서 연결 상태를 확인하는 중… `body`, `text-muted`. 진행 표시는 `primary` 색(제안) |
| 실패 | 오류 카드 | 테두리 `border`, `radius-lg`, 안쪽 여백 24. 경고 아이콘 + 문구(색만으로 구분하지 않음). 카드 최대 폭은 **확인 필요** (제안: 대화상자와 같은 560px) |
| | 제목 | 문서 연결 상태를 확인할 수 없습니다. `title`(태블릿 20/28) |
| | 설명 | 서버 연결을 확인한 뒤 다시 시도하거나 문서 연결 설정을 열어 주세요. `body`, `text-muted` |
| | 다시 확인 | 주 버튼. 버튼 `lg`(높이 56), `primary`. 태블릿은 오른쪽 |
| | 문서 연결 설정 | 보조 버튼 → `/settings/document`. 버튼 `lg`(높이 56), `primary-soft`. 주 버튼과 8 이상 띄움 |

### 3.2 태블릿 가로 (폭 960px 이상)

세로 배치를 그대로 쓰고 본문 최대 폭 1040px 안에서 카드를 가운데에 둔다.

### 3.3 휴대폰 (폭 600px 미만)

- 1단, 좌우 여백 16px. 오류 카드는 테두리 없이 본문 폭 가득 표시한다.
- 두 버튼은 화면 폭 가득 세로로 쌓는다(위: 다시 확인, 아래: 문서 연결 설정, 사이 8). 하단 탭 바가 보이면 탭 바 바로 위에, 보이지 않으면 아래쪽 안전 영역만큼 띄워 고정한다.
- 높이가 낮은 화면(`short`, 높이 560px 이하)에서는 고정 버튼을 본문 끝으로 옮긴다.

## 4. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 회의록 목록(MIN-01), 설정(SET-01) 등은 점검 없이 열리고, 메인·새 회의·참석자만 점검한다.
- **제안**
  - 로그인 점검(신규) → 문서 연결 점검 순서로 통합한다.
  - 확인 중 상태는 빈 문구 대신 레이아웃 골격(Skeleton)으로 표시한다. 골격은 기기별 배치(태블릿 레일 + 본문, 휴대폰 상단 바 + 탭 바)와 같은 모양으로 그린다.
  - 미연결 시 바로 이동하지 않고 "문서 서비스를 먼저 연결해 주세요" 안내 카드와 연결 버튼을 보여 주는 방안 검토. 안내 카드는 위 실패 카드와 같은 크기·버튼 배치를 쓴다.
- **확인 필요** — D-05: 일반 사용자가 미연결 상태를 만났을 때 직접 연결할 수 있게 할지, 관리자에게 요청하도록 안내할지.
- **확인 필요 (배치)** — 점검 중·실패 상태에서 공통 레이아웃(레일·탭 바)을 함께 보일지. 오류 카드 최대 폭(제안 560px)은 8장에 기준이 없다.
