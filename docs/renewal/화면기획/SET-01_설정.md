# SET-01 설정

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-01 |
| 유형 | 페이지 (설정 카드 모음) |
| 경로 | `/settings` |
| 현재 구현 | `frontend/src/SettingsPage.tsx`, `settingsApi.ts`, `emailSettingsApi.ts`, `slackSettingsApi.ts`, `emailSettingsStorage.ts`, `slackWebhookStorage.ts` (Slack 관련 파일은 리뉴얼 시 삭제, D-11) |
| 진입 조건 | 로그인(신규). 관리자 구분 없음(D-05) |
| 연결 화면 | 문서 연결 설정 → SET-02 |
| 사용 API | API-001 앱 설정, API-019 연동 상태, API-035 Gmail 설정 조회·저장·삭제, API-036 Gmail 연결 시험. API-038·039(Slack)는 쓰지 않는다(D-11) |
| 현행 캡처 | [설정 화면](<../현_UI/설정 화면.png>) |

## 1. 화면 개요

회의록 저장(문서 서비스)과 이메일 전달(Gmail) 연동 상태를 확인하고 설정한다. Slack 알림은 폐기했다(D-11).

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-01-F01 | 문서 연결 요약 | 연결 서비스와 상태 | "{서비스}에 회의록과 기본 템플릿을 저장합니다." + 문서 연결 설정(SET-02) |
| SET-01-F02 | 이메일 설정 입력 | 발신 주소, Google 클라이언트 ID, 클라이언트 보안 키, 연결 토큰(Refresh Token) | 4개 모두 필수. 비밀값은 비밀번호 입력란 |
| SET-01-F03 | 이메일 저장·연결 확인 | 저장 후 자동 연결 시험 | 저장(API-035 PUT) → 시험(API-036). 시험 실패 시 오류 표시, 저장값은 유지 |
| SET-01-F04 | 이메일 설정 보기·수정·삭제 | 설정 완료 시 마스킹 표시 | 수정 → 빈 입력란으로 다시 입력, 취소 가능. 삭제 |
| SET-01-F05 | (폐기) Slack 설정 | - | **폐기 (D-11)**. 리뉴얼 화면에 Slack 카드를 두지 않는다 |
| SET-01-F06 | 상태 배지 | 서비스별 연결 상태 | 아래 상태 문구 표 |
| SET-01-F07 | 전체 새로고침 | 모든 연결 상태 다시 조회 | API-001 + API-019 |
| SET-01-F08 | 브라우저 복구 | 서버 설정이 비어 있으면 브라우저에 보관한 Gmail 설정으로 복원 | 앱 시작 시 실행. 유지한다(D-09 결정). Slack 값 보관·복구는 없앤다(D-11) |
| SET-01-F09 | 시험 메일 발송 | 발신 주소로 시험 메일 | **제안**: API-037은 있으나 화면에서 사용하지 않음 |

### 상태 문구 (현행)

| 상태 | 문구 |
|---|---|
| 정상 | 연결 상태 확인됨(문서) / 연결 확인됨(이메일) |
| 미선택 | 문서 서비스를 선택해 연결할 수 있습니다. |
| 미설정 | 설정 확인이 필요합니다. |
| 연결 불가 | 연결 상태를 확인하지 못했습니다. |
| 구조 접근 불가 | 서비스 연결은 확인했지만 필수 Meetings 또는 Participants 구조에 접근할 수 없습니다. |
| 조회 실패 | 연결 상태를 불러오지 못했습니다. |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4·8장을 따른다. 공통 틀(내비게이션 레일, 상단 바, 하단 탭 바)은 CMN-01을 따른다.

### 3.1 태블릿 (기준, 600px 이상)

카드를 위에서 아래로 쌓는 1단 배치다.

```
┌──────┬──────────────────────────────────────────────────────┐
│ [로고]│ 설정                                                  │  상단 바 64px
│      ├──────────────────────────────────────────────────────┤
│  ⌂   │ ┌ 문서 연결 ─────────────────────────── [✓ 연결됨] ┐ │
│  홈   │ │ (N) Notion · 회의록과 기본 템플릿을 저장합니다.    │ │
│  ▤   │ │                                [문서 연결 관리 →] │ │
│ 회의록 │ └────────────────────────────────────────────────┘ │
│  👥  │ ┌ 이메일 (Gmail) ───────────────── [⚠ 설정 필요] ┐ │
│ 참석자 │ │ 발신 이메일 주소                                  │ │
│  ⚙   │ │ [name@gmail.com                              ]  │ │  입력란 52
│  설정  │ │ ▸ 고급: Google OAuth 정보                    (접힘) │ │  행 60
│      │ │   클라이언트 ID   [••••••••••••••••••    ] [👁]  │ │
│      │ │   보안 키         [••••••••••••••••••    ] [👁]  │ │
│      │ │   연결 토큰       [••••••••••••••••••    ] [👁]  │ │
│      │ │                    [시험 메일 보내기]  [  저장  ]  │ │  버튼 48
│      │ └────────────────────────────────────────────────┘ │
│  [👤] │                                                      │
│      │                          [모든 연결 상태 새로고침]    │
└──────┴──────────────────────────────────────────────────────┘
 레일 88px
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 바 (64px) | 제목 | 제목(h1) | 설정. `headline` |
| 공통 카드 | 카드 | 카드 | 흰 배경 + 테두리 `border`(그림자 없음), 모서리 `radius-lg`, 안쪽 여백 24, 카드 사이 32 |
| | 카드 제목 + 상태 배지 | 카드 머리 | 제목 `title`. 배지는 아이콘 + 문구, 모서리 `radius-sm`, 글자 `caption`. 색: 정상 `success-soft`, 미설정 `warning-soft`, 연결 불가·구조 접근 불가·조회 실패 `danger-soft`, 미선택 `bg-subtle` + `text-muted`(제안). 색만으로 구분하지 않는다 |
| 문서 연결 카드 | 설명 | 텍스트 | {서비스}에 회의록과 기본 템플릿을 저장합니다. `body` |
| | 문서 연결 설정 | 보조 버튼 `md` 48 | SET-02. `primary-soft` |
| 이메일 카드 | 발신 이메일 주소 | 이메일 입력 | placeholder "name@gmail.com". 입력란 52, 글자 16px. `type=email`, `autocomplete=email`로 이메일 키보드를 연다(제안) |
| | Google 클라이언트 ID | 비밀 입력 | 설정 후 마스킹·읽기 전용. 입력란 52, 글자 16px |
| | Google 클라이언트 보안 키 | 비밀 입력 | 〃 |
| | 메일 전송용 연결 토큰 | 비밀 입력 | 〃 |
| | 보기 토글 | 아이콘 버튼 48 | **제안**: 비밀 입력란 오른쪽에 붙인다. 긴 값을 붙여넣은 뒤 터치 화면에서 눈으로 확인할 수 있게 한다. 설정 완료 후 마스킹 상태에서는 표시하지 않는다 |
| | 고급 접힘 머리 | 접힘 영역 | **제안**(5장). 머리 행은 1줄 목록 행 60(휴대폰 56) 전체가 누르는 영역 |
| | 저장 / 취소 | 버튼 `md` 48 | 편집 중. 4개 모두 입력 시 저장 활성. 저장 중 "연결 확인 중…". 저장은 주 버튼(`primary`), 취소는 보조 버튼 |
| | 수정 / 삭제 | 버튼 `md` 48 | 설정 완료 시. 삭제는 `danger` 계열, 두 버튼 사이 8px 이상 |
| | 오류 | 경고 텍스트 | `danger-soft` 안내 상자 + 아이콘. 저장 성공·시험 성공 안내는 `success-soft` |
| 하단 | 모든 연결 상태 새로고침 | 보조 버튼 `md` 48 | 조회 완료 후 표시 |
| 삭제 확인 (제안, 5장) | 대화상자 | 확인 팝업 | 휴대폰 하단 시트 / 태블릿 가운데 최대 560px. 삭제 버튼 `danger` |

**긴 값 붙여넣기 (터치 키보드)**

- 클라이언트 ID·보안 키·연결 토큰은 길어서 직접 입력하지 않고 붙여넣는다고 본다.
- 비밀 입력란은 자동 대문자·자동 수정·맞춤법 검사를 끈다(제안). 붙여넣은 값의 앞뒤 공백은 저장 전에 제거한다(제안, 현행 처리 여부 확인 필요).
- 붙여넣기는 입력란을 길게 눌러 여는 기기 기본 메뉴를 쓴다. 별도 "붙여넣기" 버튼은 브라우저 클립보드 읽기 권한이 필요하므로 **확인 필요**(제안: 만들지 않음).

### 3.2 태블릿 가로 (960px 이상)

왼쪽 섹션 목차 + 오른쪽 카드 2단을 쓴다(제안).

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│ [로고]│ 설정                                                              │
│      ├──────────────┬───────────────────────────────────────────────────┤
│  ⌂   │ 문서 연결   ✓ │ ┌ 문서 연결 ──────────────────────── [✓ 연결됨] ┐ │
│  ▤   │ 이메일      ⚠ │ │ ...                                           │ │
│  👥  │ (계정)        │ └───────────────────────────────────────────────┘ │
│  ⚙   │              │ ┌ 이메일 (Gmail) ──────────────── [⚠ 설정 필요] ┐ │
│      │              │ │ ...                                           │ │
└──────┴──────────────┴───────────────────────────────────────────────────┘
```

| 영역 | 요소 | 내용·규칙 |
|---|---|---|
| 섹션 목차 | 항목 | 1줄 목록 행 60. 항목 이름 + 상태 아이콘. 누르면 해당 카드로 이동. 현재 보고 있는 섹션은 `selected` 배경 |
| | 폭 | 보조 단 280px (스타일 방식 검토 8.6 보조 크기) |
| 카드 영역 | 카드 | 3.1과 같음. 좌우 여백 32px, 본문 최대 폭 1040px 안에서 가운데 정렬 |

### 3.3 휴대폰 (600px 미만)

- 카드를 1단으로 쌓는다. 좌우 여백 16px, 카드 안쪽 여백 16px, 카드 사이 24px.
- 입력란 높이 48, 글자 16px. 이름표는 입력란 위(`label`).
- 카드 안 버튼은 폭 가득으로 세로로 쌓는다(주 버튼이 위). 화면 하단 고정 버튼은 두지 않는다. 카드가 여러 개라 고정 버튼이 어느 카드의 저장인지 모호해지기 때문이다.
- 상태 배지가 제목과 한 줄에 들어가지 않으면 제목 아래 줄로 내린다.
- 섹션 목차는 두지 않는다.
- `short`(높이 560px 이하, 키보드 열림)에서는 상단 바와 여백을 줄이고, 초점이 간 입력란과 그 카드의 저장 버튼이 키보드에 가리지 않게 스크롤한다.
- 삭제 확인(제안)은 하단 시트로 연다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 상태 조회 중 | "연결 상태를 불러오는 중…" |
| 둘 다 조회 실패 | "설정과 연결 상태를 불러오지 못했습니다." + 전체 다시 불러오기 |
| 일부 조회 실패 | 확인 가능한 정보 표시 + 경고 + 다시 확인 |
| 이메일 설정 불러오는 중 | 카드 안 "…설정을 불러오는 중…" |
| 저장·시험 실패 | 카드 안 오류 문구 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)**
  - Google OAuth 클라이언트 ID·보안 키·Refresh Token을 일반 사용자 화면에 그대로 요구한다. 용어가 어렵고 발급 방법 안내가 없다.
  - 삭제 버튼에 확인 단계가 없다.
  - 저장 버튼이 보조 스타일이라 주 행동이 드러나지 않는다(캡처).
- **사실 (코드 확인)** — Gmail 설정값(클라이언트 보안 키, 연결 토큰 포함)과 Slack Webhook 주소를 브라우저 `localStorage`에 평문으로 저장하고, 앱 시작 시 서버 설정이 비어 있으면 이 값으로 다시 저장한다(`emailSettingsStorage.ts`, `slackWebhookStorage.ts`, `App.tsx`).
- **제안**
  - 이메일 카드는 발신 주소만 기본 노출하고 OAuth 정보는 "고급" 접힘 영역 + 발급 안내 링크
  - 화면 배치는 D-06(태블릿 기준, 결정)에 따라 태블릿 1단 카드, 태블릿 가로 목차 + 카드 2단, 휴대폰 1단 카드로 한다(3장)
  - 시험 메일 보내기(API-037), 삭제 확인 팝업 추가
- **결정 (2026-11-06)**
  - D-03: 로그인 인증 코드 메일도 이 Gmail 설정으로 보낸다. Gmail이 설정되지 않았으면 로그인 화면의 "메일 설정"(AUTH-01-F07)에서 같은 설정을 입력할 수 있다.
  - D-05: 관리자 구분 없음.
  - D-09: Gmail 설정의 브라우저 보관·복구를 유지한다. 연결하는 Gmail은 회의록 발송 전용 계정이다.
  - D-11: Slack 알림을 완전히 폐기한다. Slack 카드, `slackSettingsApi.ts`, `slackWebhookStorage.ts`와 앱 시작 시 Slack 복구를 없앤다.
