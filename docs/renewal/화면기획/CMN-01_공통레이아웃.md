# CMN-01 공통 레이아웃

| 항목 | 내용 |
|---|---|
| 화면 ID | CMN-01 |
| 유형 | 레이아웃 (모든 화면의 틀) |
| 경로 | 전체 (AUTH 화면은 별도 레이아웃) |
| 현재 구현 | `frontend/src/App.tsx` (`app-shell`, `product-header`, `BottomNavigation`), `components/NavigationLeaveGuard.tsx`, `components/Toast.tsx` |
| 진입 조건 | 로그인 완료 (신규, D-01) |
| 하위 팝업 | CMN-01-P01 페이지 이탈 확인, CMN-01-P02 로그아웃 확인 (신규) |
| 현행 캡처 | [메인 화면](<../현_UI/메인 화면.png>) — 상단 헤더와 하단 탭 바 |

## 1. 화면 개요

로그인 이후 모든 화면이 공유하는 머리글, 주 메뉴, 본문 영역, 알림(Toast), 이탈 방지 규칙을 정의한다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| CMN-01-F01 | 브랜드 표시 | Windsoft Minutes 로고, 클릭 시 메인 이동 | 현행 유지 |
| CMN-01-F02 | 주 메뉴 | 홈, 회의록, 참석자, 설정 | 현재 경로에 해당하는 메뉴 강조 |
| CMN-01-F03 | 메뉴 숨김 | 녹음 중·처리 중·문서 연결 화면에서 메뉴 숨김 | 현행: `/meetings/:id/recording`(녹음 중·일시정지), `/meetings/:id/processing`, `/setup/document`, `/settings/document`에서 하단 탭 바 숨김 |
| CMN-01-F04 | 새 회의 바로가기 | 어느 화면에서나 새 회의 시작 | **제안**: 데스크톱 상단 바에 주 버튼 배치 |
| CMN-01-F05 | 사용자 정보·로그아웃 | 로그인한 이메일 표시, 로그아웃 | **신규**. 로그아웃 시 CMN-01-P02 확인 후 AUTH-01 이동 |
| CMN-01-F06 | 문서 연결 상태 표시 | 연결된 서비스와 상태 배지 | **제안**: 현행 HOME-01 우측 상단 아이콘을 공통 상단 바로 이동 |
| CMN-01-F07 | 이탈 방지 | 녹음 중, 처리 중, 저장 안 된 검토 내용이 있을 때 화면 이동 경고 | 현행: 링크 클릭·뒤로 가기는 `window.confirm`, 새로고침·닫기는 브라우저 기본 경고 |
| CMN-01-F08 | Toast 알림 | 저장·삭제 결과 등 짧은 알림 | 현행: 상단 중앙 고정. 화면 제목을 가리는 문제 있음 |
| CMN-01-F09 | 인증 만료 처리 | 세션 만료 시 로그인 화면으로 이동 | **신규**. 진행 중 작업(녹음 등)이 있으면 즉시 이동하지 않고 안내 (확인 필요) |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안, 1280px 이상)

```
┌──────────────┬───────────────────────────────────────────────┐
│ [로고]        │ 페이지 제목            [문서 연결 ●] [+ 새 회의] │
│              ├───────────────────────────────────────────────┤
│ ⌂ 홈          │                                               │
│ ▤ 회의록      │   본문 (최대 폭 1200px, 좌우 여백 32px)          │
│ 👥 참석자     │                                               │
│ ⚙ 설정        │                                               │
│              │                                               │
│ ──────────── │                                               │
│ user@회사.com │                                               │
│ 로그아웃       │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 사이드바 (폭 240px) | 로고 | 링크 | 메인 이동 |
| | 주 메뉴 4개 | 내비게이션 | 아이콘 + 텍스트, 활성 메뉴 배경 강조 |
| | 사용자 영역 | 텍스트 + 버튼 | 로그인 이메일, 로그아웃 |
| 상단 바 (높이 64px) | 페이지 제목 | 제목(h1) | 화면별 제목. 상세 화면은 뒤로 가기 포함 |
| | 문서 연결 상태 | 상태 칩 | 서비스 아이콘 + 상태 점(연결됨·점검 필요·미연결). 클릭 시 HOME-01-P01 |
| | 새 회의 | 주 버튼 | MTG-01 이동. 녹음·처리 화면에서는 숨김 |
| 본문 | 콘텐츠 | 영역 | 화면별 정의 |
| 전역 | Toast | 알림 | **제안**: 우측 하단 또는 상단 바 아래, 제목과 겹치지 않게 |

### 3.2 태블릿 (제안, 768~1279px)

- 사이드바를 아이콘만 보이는 72px 폭으로 접는다. 마우스를 올리거나 펼치기 버튼을 누르면 펼친다.

### 3.3 모바일 (제안, 767px 이하)

- 상단 헤더(로고, 문서 연결 상태, 사용자 메뉴)와 하단 탭 바(홈, 회의록, 참석자, 설정) — 현행 구조를 유지하되 디자인 품질을 개선한다.
- 하단 고정 주 버튼(예: 새 회의 시작, 참석자 추가)은 탭 바 위에 배치한다.

### 3.4 CMN-01-P01 페이지 이탈 확인

| 요소 | 내용 |
|---|---|
| 제목 | 이 화면을 나갈까요? (제안) |
| 본문 | 현행 문구: "진행 중이거나 저장되지 않은 내용이 있습니다. 화면을 벗어나면 작업이나 수정 내용이 사라질 수 있습니다. 이동하시겠습니까?" |
| 버튼 | 머무르기(기본 초점) / 나가기 |
| 규칙 | 앱 내부 이동은 디자인된 모달로 교체(제안). 새로고침·탭 닫기는 브라우저 기본 경고만 가능 |

### 3.5 CMN-01-P02 로그아웃 확인 (신규)

| 요소 | 내용 |
|---|---|
| 제목 | 로그아웃할까요? |
| 버튼 | 취소 / 로그아웃 |
| 규칙 | 녹음·처리 중에는 메뉴를 숨기므로 노출되지 않는다. 로그아웃 후 AUTH-01 이동 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 일반 | 사이드바(또는 탭 바) + 상단 바 + 본문 |
| 집중 모드 (녹음·처리·문서 연결 진행) | 메뉴 숨김, 상단 바는 제목만 표시 |
| Backend 연결 끊김 | CMN-02 오버레이 표시 |
| 세션 만료 (신규) | 안내 후 AUTH-01 이동 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)**
  - 데스크톱에서도 모바일용 하단 탭 바와 넓게 늘어난 단일 컬럼을 그대로 쓴다.
  - 화면마다 하단 고정 버튼(새 회의 시작, 참석자 추가)이 다르게 배치된다.
  - Toast가 화면 제목 위에 겹쳐 표시된다(캡처: 문서 연결 진행·성공).
- **개선 방향 (제안)** — 사이드바 레이아웃, 공통 상단 바, 일관된 주 버튼 위치, 디자인된 이탈 확인 모달
- **확인 필요** — D-01(인증), D-05(관리자 메뉴 분리 여부), D-06(Breakpoint)
