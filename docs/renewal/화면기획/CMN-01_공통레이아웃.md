## 1. 화면 개요

로그인 이후 모든 화면이 공유하는 머리글, 주 메뉴, 본문 영역, 알림(Toast), 이탈 방지 규칙을 정의한다.

## 2. 기능 정의

|---|---|---|---|
| CMN-01-F01 | 브랜드 표시 | Downforce Minutes 로고(다운포스 CI), 클릭 시 메인 이동 | 현행: Windsoft Minutes 로고. 리뉴얼에서 다운포스 CI로 교체(D-10) |

## 3. 화면 구성 요소

### 3.1 태블릿 (기준, 폭 600px 이상)

화면 기준은 마이크가 있는 태블릿이다. PC 전용 배치는 만들지 않는다(D-06). 크기·글자·컴포넌트 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 8장을 따른다.

```
┌──────┬──────────────────────────────────────────────┐
│ [로고]│ ← 페이지 제목              [문서 연결 ●] [+ 새 회의] │  상단 바 64px
│      ├──────────────────────────────────────────────┤
│  ⌂   │                                              │
│  홈   │   본문 (좌우 여백 24px, 가로 화면 32px)           │
│  ▤   │   가로 화면(960px 이상)은 필요한 화면만 2단        │
│ 회의록 │   본문 최대 폭 1040px, 넓은 화면은 가운데 정렬     │
│  👥  │                                              │
│ 참석자 │                                              │
│  ⚙   │                                              │
│  설정  │                                              │
│      │                                              │
│  [👤] │                                              │
└──────┴──────────────────────────────────────────────┘
 레일 88px
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 내비게이션 레일 (폭 88px, 왼쪽 고정, `tablet` 600~959px) | 로고 | 링크 | 심볼 로고(다운포스 CI 페이지의 Symbol 이미지, D-10, 2026-11-09). 메인 이동 |
| | 주 메뉴 4개 | 내비게이션 | 아이콘 24px + 이름(`nav`), 항목 64×56px. 선택된 메뉴는 `selected` 색(분홍 계열, S-09) 배경 |
| 사이드바 (폭 240px, 왼쪽 고정, `tablet-lg` 960px 이상, S-11) | 로고 | 링크 | 글자 로고 "DOWNFORCE" + "Minutes"(시안). 메인 이동 |
| | 주 메뉴 4개 | 내비게이션 | 아이콘 24px + 이름(`label`) 가로 배치, 항목 높이 56. 선택 메뉴 `selected` 배경 + `selected-text` 글자 |
| | 계정 | 이메일 + 로그아웃 | 아래쪽에 로그인 이메일과 로그아웃 버튼을 직접 보인다(시안). 로그아웃은 CMN-01-P02 확인 |
| | 사용자 | 아이콘 버튼 | 로그인 이메일·로그아웃 메뉴 (CMN-01-F05) |
| 상단 바 (높이 64px) | 페이지 제목 | 제목(h1) | `headline`. 상세 화면은 뒤로 가기 포함 |
| | 문서 연결 상태 | 상태 칩 | 서비스 아이콘 + 상태 점(연결됨·점검 필요·미연결) + 문구. 누르면 HOME-01-P01 |
| | 새 회의 | 주 버튼 `md` 48 | MTG-01 이동. HOME-01, MTG-01~MTG-05, 집중 모드 화면에서는 숨김(CMN-01-F04) |
| 본문 | 콘텐츠 | 영역 | 화면별 정의 |
| 전역 | Toast | 알림 | 화면 하단 가운데, 최대 폭 480px. 페이지 제목과 겹치지 않음 |

### 3.2 휴대폰 (폭 600px 미만)

- 상단 바(높이 56px): 페이지 제목, 뒤로 가기, 문서 연결 상태, 사용자 메뉴
- 하단 탭 바(높이 64px + 하단 안전 영역): 홈, 회의록, 참석자, 설정
- 화면의 주 버튼(예: 새 회의 시작, 참석자 추가)은 탭 바 위에 화면 폭 가득 고정한다.
- 높이가 낮은 화면(휴대폰 가로, 키보드 열림, 높이 560px 이하)에서는 상단 바와 여백을 줄이고, 고정 버튼을 본문 끝으로 옮긴다.

### 3.3 PC

- 고려하지 않는다(D-06). 넓은 화면에서는 태블릿 가로 배치를 본문 최대 폭 1040px로 가운데 정렬해 보여 준다.
- 마우스 hover에만 의존하는 동작(hover로 펼치는 메뉴 등)은 만들지 않는다.

### 3.4 CMN-01-P01 페이지 이탈 확인

| 요소 | 내용 |
|---|---|
| 제목 | 이 화면을 나갈까요? (제안) |
| 본문 | 현행 문구: "진행 중이거나 저장되지 않은 내용이 있습니다. 화면을 벗어나면 작업이나 수정 내용이 사라질 수 있습니다. 이동하시겠습니까?" |
| 버튼 | 머무르기(기본 초점) / 나가기 |
| 규칙 | 앱 내부 이동은 디자인된 모달로 교체(제안). 새로고침·탭 닫기는 브라우저 기본 경고만 가능 |

### 3.5 CMN-01-P02 로그아웃 확인 (신규)

| 요소 | 내용 |
|---|---|
| 제목 | 로그아웃할까요? |
| 버튼 | 취소 / 로그아웃 |
| 규칙 | 녹음·처리 중에는 메뉴를 숨기므로 노출되지 않는다. 로그아웃 후 AUTH-01 이동 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 일반 | 내비게이션 레일(태블릿) 또는 하단 탭 바(휴대폰) + 상단 바 + 본문 |
| 집중 모드 (MTG-02, MTG-03, SET-03~SET-06) | 메뉴(레일·탭 바) 숨김, 상단 바는 제목과 뒤로 가기만 표시. Toast는 하단 고정 버튼 위 16px, 버튼이 없으면 하단 안전 영역 위 16px |
| Backend 연결 끊김 | CMN-02 오버레이 표시 |
| 세션 만료 (신규) | 안내 후 AUTH-01 이동 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)**
  - 데스크톱에서도 모바일용 하단 탭 바와 넓게 늘어난 단일 컬럼을 그대로 쓴다.
  - 화면마다 하단 고정 버튼(새 회의 시작, 참석자 추가)이 다르게 배치된다.
  - Toast가 화면 제목 위에 겹쳐 표시된다(캡처: 문서 연결 진행·성공).
- **개선 방향 (제안)** — 태블릿 내비게이션 레일·휴대폰 하단 탭 바 레이아웃, 공통 상단 바, 일관된 주 버튼 위치, 디자인된 이탈 확인 모달
- **결정됨** — D-01(인증 API만 신규), D-05(관리자 메뉴 구분 안 함), D-06(태블릿 기준), 인증 만료 시 진행 중 작업 유지(F09), 로그아웃은 HOME 묶음(F05)
