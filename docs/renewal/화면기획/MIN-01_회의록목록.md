# MIN-01 회의록 목록

| 항목 | 내용 |
|---|---|
| 화면 ID | MIN-01 |
| 유형 | 페이지 (목록) |
| 경로 | `/meetings` |
| 현재 구현 | `frontend/src/MeetingHistory.tsx` `MeetingsPage`·`MeetingList`, `ProcessingFailureList.tsx`, `meetingFilters.ts` |
| 진입 조건 | 로그인(신규). 현행은 문서 연결 점검(CMN-04) 없이 열림 |
| 연결 화면 | 행 클릭 → MIN-02 / 새 회의 시작 → MTG-01 / 실패 회의 재처리 → MTG-03 |
| 사용 API | API-017 회의 목록, API-033 처리 실패 목록, API-020 처리 재시도 |
| 현행 캡처 | [회의록 화면](<../현_UI/회의록 화면.png>) (빈 상태) |

## 1. 화면 개요

문서 서비스에 저장된 지난 회의 목록을 보고 검색한다. 처리에 실패한 회의가 있으면 목록 위에서 다시 처리할 수 있다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MIN-01-F01 | 회의 목록 | 저장된 회의 표시 | 현행: 서버에서 받은 목록을 화면에서 최대 100건 표시. 페이지 나누기 없음 |
| MIN-01-F02 | 검색 | 회의명 또는 참석자 | 현행: 입력 후 Enter 또는 입력란 벗어날 때 적용, 화면 내 필터 |
| MIN-01-F03 | 기간 필터 | 시작일 ~ 종료일 | "상세 조건"으로 펼침. 날짜 변경 즉시 적용. 시작일 > 종료일이면 기간 미적용 + 오류 |
| MIN-01-F04 | 검색 초기화 | 검색어 지우기 | - |
| MIN-01-F05 | 결과 건수 | 총 n건 | - |
| MIN-01-F06 | 상세 이동 | 행 클릭 | MIN-02 |
| MIN-01-F07 | 처리 실패 내역 | 실패 회의 목록 | 0건이면 영역 숨김. 제목, 실패 배지, 일시, 실패 단계, 오디오 만료 시각 |
| MIN-01-F08 | 회의 다시 처리 | 실패 회의 재처리 | 서버 허용 시. 성공하면 MTG-03 이동. 오디오 만료 시 오류 |
| MIN-01-F09 | 새 회의 시작 | MTG-01 이동 | 현행 하단 고정 버튼 |
| MIN-01-F10 | 정렬 | 날짜순 | **제안**: 최신순/오래된순 (현행은 서버 응답 순서) |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안)

```
┌ 상단 바: 회의록                                         [+ 새 회의] ┐
│ ┌ ⚠ 처리 실패 2건 ─────────────────────────────────────────────┐ │
│ │ 주간 회의 [실패] 11월 5일 10:00 · 음성 인식 실패 · 오디오 만료 11/6 10:00 [다시 처리] │
│ └─────────────────────────────────────────────────────────────┘ │
│ [🔍 회의명 또는 참석자          ] [기간: 2026-11-01 ~ 2026-11-05 ▾] │
│ 총 24건                                                최신순 ▾  │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │ 회의명              │ 일시               │ 참석자              │ │
│ │ 주간 회의            │ 2026.11.05 10:00   │ 홍길동, 김철수 외 2명 │ │
│ │ 기획 리뷰            │ 2026.11.04 14:00   │ ...                │ │
│ └──────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 | 제목 | 제목 | 현행 "회의 기록" → 메뉴명과 같게 "회의록" (제안) |
| 처리 실패 | 섹션 제목 | 제목 | 처리 실패 내역 (n건) |
| | 실패 행 | 목록 행 | 제목, "실패" 배지, 일시, "{단계} 실패", 오디오 만료 시각 또는 "보관된 오디오가 없어 재처리할 수 없습니다." |
| | 회의 다시 처리 | 보조 버튼 | 처리 중 "시작 중…", 다른 행 처리 중이면 비활성 |
| | 오류 + 새로고침 | 경고 | 실패 목록 조회 실패 시 |
| 검색 | 검색 입력 | 검색 상자 | placeholder "회의명 또는 참석자", 지우기(×) |
| | 기간 | 날짜 범위 | 시작일·종료일. 데스크톱은 항상 노출(제안), 모바일은 "상세 조건"으로 접기 |
| 결과 | 건수 | 텍스트 | 총 n건 |
| | 목록 | 표(데스크톱) / 카드(모바일) | 회의명, 일시, 참석자(최대 3명 + 외 n명). 행 전체 클릭 |
| 실행 | 새 회의 | 주 버튼 | CMN-01 상단 바로 이동(제안) |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 로딩 | 표 골격(제안). 현행: "회의 목록을 불러오는 중…" |
| 회의 없음 | 일러스트 + "회의 기록이 없습니다. 회의를 완료하면 여기에 표시됩니다." + 새 회의 버튼 (현행은 문구가 시각적으로 숨겨짐) |
| 검색 결과 없음 | "검색 결과가 없습니다." + 조건 초기화 (제안) |
| 기간 오류 | "시작일은 종료일보다 늦을 수 없습니다. 날짜 범위는 적용하지 않았습니다." |
| 조회 실패 | 오류 카드 + 다시 시도. 이전 목록이 있으면 유지하고 경고만 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 빈 상태가 아이콘만 있어 의미가 약하다. 검색이 Enter·포커스 이동 시에만 적용돼 즉시성이 떨어진다. 메뉴명(회의록)과 화면 제목(회의 기록)이 다르다.
- **제안** — 입력 중 즉시 검색(지연 적용), 데스크톱 표 형식, 정렬, 처리 중인 회의(진행 상태) 표시 여부 검토.
- **확인 필요** — API-017이 서버 측 검색·페이지 나누기를 지원하는지 확인. 현행은 전체를 받아 화면에서 거르며, 100건 초과 시 이후 회의가 보이지 않을 수 있다.
