# MIN-01 회의록 목록

| 항목 | 내용 |
|---|---|
| 화면 ID | MIN-01 |
| 유형 | 페이지 (목록) |
| 경로 | `/meetings` |
| 현재 구현 | `frontend/src/MeetingHistory.tsx` `MeetingsPage`·`MeetingList`, `ProcessingFailureList.tsx`, `meetingFilters.ts` |
| 진입 조건 | 로그인(신규). 현행은 문서 연결 점검(CMN-04) 없이 열림 |
| 연결 화면 | 행 클릭 → MIN-02 / 새 회의 시작 → MTG-01 / 실패 회의 재처리 → MTG-03 |
| 사용 API | API-017 회의 목록, API-033 처리 실패 목록, API-020 처리 재시도 |
| 현행 캡처 | [회의록 화면](<../현_UI/회의록 화면.png>) (빈 상태) |

## 1. 화면 개요

문서 서비스에 저장된 지난 회의 목록을 보고 검색한다. 처리에 실패한 회의가 있으면 목록 위에서 다시 처리할 수 있다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MIN-01-F01 | 회의 목록 | 저장된 회의 표시 | 현행: 서버에서 받은 목록을 화면에서 최대 100건 표시. 페이지 나누기 없음 |
| MIN-01-F02 | 검색 | 회의명 또는 참석자 | 현행: 입력 후 Enter 또는 입력란 벗어날 때 적용, 화면 내 필터 |
| MIN-01-F03 | 기간 필터 | 시작일 ~ 종료일 | "상세 조건"으로 펼침. 날짜 변경 즉시 적용. 시작일 > 종료일이면 기간 미적용 + 오류 |
| MIN-01-F04 | 검색 초기화 | 검색어 지우기 | - |
| MIN-01-F05 | 결과 건수 | 총 n건 | - |
| MIN-01-F06 | 상세 이동 | 행 클릭 | MIN-02 |
| MIN-01-F07 | 처리 실패 내역 | 실패 회의 목록 | 0건이면 영역 숨김. 제목, 실패 배지, 일시, 실패 단계, 오디오 만료 시각 |
| MIN-01-F08 | 회의 다시 처리 | 실패 회의 재처리 | 서버 허용 시. 성공하면 MTG-03 이동. 오디오 만료 시 오류 |
| MIN-01-F09 | 새 회의 시작 | MTG-01 이동 | 현행 하단 고정 버튼 |
| MIN-01-F10 | 정렬 | 날짜순 | **제안**: 최신순/오래된순 (현행은 서버 응답 순서) |

## 3. 화면 구성 요소

### 3.1 태블릿 (기준, 폭 600px 이상)

화면 기준은 마이크가 있는 태블릿 세로(폭 820px 전후)다. 공통 틀(내비게이션 레일 88px, 상단 바 64px)은 CMN-01을 따르고, 크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4·8장을 따른다. 목록은 표가 아니라 누르기 쉬운 목록 행으로 표시한다.

```
┌──────┬──────────────────────────────────────────────┐
│ [로고]│ 회의록                [문서 연결 ●] [+ 새 회의] │  상단 바 64px
│      ├──────────────────────────────────────────────┤
│  ⌂   │ ┌ ⚠ 처리 실패 2건 ───────────────────────┐    │
│  홈   │ │ 주간 회의 [실패]               [다시 처리] │    │  실패 행
│  ▤   │ │ 11월 5일 10:00 · 음성 인식 실패          │    │
│ 회의록 │ │ 오디오 만료 11/6 10:00                  │    │
│  👥  │ └────────────────────────────────────────┘    │
│ 참석자 │ [🔍 회의명 또는 참석자          ×] [기간 ▾]    │  입력란 52px
│  ⚙   │ 총 24건                              [최신순 ▾] │
│  설정  │ ┌────────────────────────────────────────┐    │
│      │ │ 주간 회의                              ›  │    │  행 2줄 76px
│      │ │ 2026.11.05 10:00 · 홍길동, 김철수 외 2명    │    │
│      │ ├────────────────────────────────────────┤    │
│      │ │ 기획 리뷰                              ›  │    │
│      │ │ 2026.11.04 14:00 · 이영희, 박민수         │    │
│      │ └────────────────────────────────────────┘    │
│  [👤] │                                              │
└──────┴──────────────────────────────────────────────┘
 레일 88px
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 바 (높이 64px) | 제목 | 제목(h1) | 현행 "회의 기록" → 메뉴명과 같게 "회의록" (제안). `headline` |
| | 새 회의 | 주 버튼 | CMN-01 상단 바 공통 버튼(제안). MTG-01 이동 |
| 처리 실패 | 섹션 제목 | 제목 | 처리 실패 내역 (n건). `title` + 경고 아이콘, 구역 면 `danger-soft` |
| | 실패 행 | 목록 행 | 제목, "실패" 배지, 일시, "{단계} 실패", 오디오 만료 시각 또는 "보관된 오디오가 없어 재처리할 수 없습니다." 1줄 제목(`label`) + 배지(`danger-soft`, `radius-sm` 8), 2줄 일시·단계(`caption`), 3줄 오디오 만료(`caption`). 3줄 행 높이는 8장에 정의 없음 — **확인 필요**(제안: 최소 2줄 행 76/72px에서 내용만큼 늘림) |
| | 회의 다시 처리 | 보조 버튼 `sm` 40 | 처리 중 "시작 중…", 다른 행 처리 중이면 비활성. 행 오른쪽에 항상 표시(누르는 영역 48) |
| | 실패 건이 많을 때 | 배치 | **제안**: 3건까지 보이고 나머지는 "모두 보기"로 펼친다. 목록 본문이 화면 아래로 밀리지 않게 하기 위해서다 |
| | 오류 + 새로고침 | 경고 | 실패 목록 조회 실패 시. `warning-soft` + 보조 버튼 `md` 48 |
| 검색 | 검색 입력 | 검색 상자 | placeholder "회의명 또는 참석자", 지우기(×, 아이콘 버튼 48×48). 높이 52px(휴대폰 48px), 글자 16px |
| | 기간 | 필터 칩 → 날짜 범위 | 시작일·종료일. 태블릿 세로는 검색 상자 옆 "기간" 칩으로 접고, 누르면 날짜 입력 2개(높이 52px)를 연다(태블릿 대화상자: 가운데 정렬 최대 560px). 기간이 적용되면 칩에 "11.01 ~ 11.05"처럼 표시하고 `selected` 색으로 강조한다. 날짜 변경 즉시 적용(현행)은 유지한다 |
| | 정렬 | 선택 칩 | F10 제안. 최신순/오래된순. 누르면 선택 메뉴(휴대폰 하단 시트) |
| 결과 | 건수 | 텍스트 | 총 n건. `caption`, `text-muted` |
| | 목록 | 목록 행 (2줄) | 회의명, 일시, 참석자(최대 3명 + 외 n명). 행 전체 클릭. 2줄 행 태블릿 76px / 휴대폰 72px: 1줄 회의명(`label` 또는 `body`, 길면 말줄임), 2줄 일시 · 참석자(`caption`, `text-muted`, 일시는 고정폭 숫자). 오른쪽 › 표시. 누른 상태는 `selected` 면. 행 사이 구분선 `border` |
| 실행 | 새 회의 | 주 버튼 | CMN-01 상단 바로 이동(제안). 현행 하단 고정 버튼(F09) |

- **보이는 양 (추정):** 태블릿 세로(820×1180)는 처리 실패 구역이 없을 때 목록 행 76px 기준 12건 안팎이 한 화면에 보인다. 처리 실패 구역(3건)이 있으면 약 7~8건이다.
- **표 형식:** 쓰지 않는다. 태블릿 세로 폭에서 회의명·일시·참석자 3열은 회의명이 자주 잘리고, 행 전체를 누르는 터치 동작과도 맞지 않는다.
- **hover 동작 없음:** 행 강조, 다시 처리 버튼은 hover 없이 항상 보이게 한다.

### 3.2 태블릿 가로 (폭 960px 이상)

목록과 필터를 함께 보이도록 2단으로 나눈다.

```
┌──────┬──────────────────────────────────────────────────────────────────┐
│ [로고]│ 회의록                                   [문서 연결 ●] [+ 새 회의] │  상단 바 64px
│      ├──────────────────────┬───────────────────────────────────────────┤
│  ⌂   │ 검색·필터 (고정)        │ ┌ ⚠ 처리 실패 2건 ───────────────────────┐ │
│  홈   │ [🔍 회의명·참석자    ×] │ │ 주간 회의 [실패] · 11월 5일 · 음성 인식 실패 [다시 처리] │
│  ▤   │                      │ └──────────────────────────────────────┘ │
│ 회의록 │ 기간                  │ 총 24건                                    │
│  👥  │ [2026-11-01        ]  │ ┌──────────────────────────────────────┐ │
│ 참석자 │ [2026-11-05        ]  │ │ 주간 회의                           › │ │  행 2줄 76px
│  ⚙   │                      │ │ 2026.11.05 10:00 · 홍길동, 김철수 외 2명 │ │
│  설정  │ 정렬                  │ ├──────────────────────────────────────┤ │
│      │ (●) 최신순 ( ) 오래된순  │ │ 기획 리뷰                           › │ │
│      │                      │ │ 2026.11.04 14:00 · 이영희, 박민수      │ │
│      │ [조건 초기화]           │ └──────────────────────────────────────┘ │
│  [👤] │                      │                                           │
└──────┴──────────────────────┴───────────────────────────────────────────┘
 레일 88px   필터 단                     목록 단 (따로 스크롤)
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 필터 단 (왼쪽) | 검색 입력 | 검색 상자 | 3.1과 같다. 높이 52px |
| | 기간 | 날짜 입력 2개 | 접지 않고 항상 노출. 높이 52px, 이름표 `label` |
| | 정렬 | 라디오 | 행 높이 48px (F10 제안) |
| | 조건 초기화 | 보조 버튼 `md` 48 | 검색 결과 없음 상태의 "조건 초기화"(제안)와 같은 동작 |
| | 단 폭 | 배치 | 280px 고정 (스타일 방식 검토 8.6 보조 크기) |
| 목록 단 (오른쪽) | 처리 실패·건수·목록 | 3.1과 같음 | 실패 행은 폭이 넓어져 1~2줄로 줄 수 있다 |
| 공통 | 스크롤 | 규칙 | 목록 단만 스크롤하고 필터 단은 고정한다. 좌우 여백 32px |

- 표 형식은 이 폭에서만 선택지로 남긴다. 쓰더라도 행 높이는 1줄 행 60px(누르는 영역 48px 이상)로 하고 행 전체를 누르는 동작을 유지한다. 기본은 목록 행이다.
- 본문 최대 폭 1040px을 넘는 화면은 가운데 정렬한다.

### 3.3 휴대폰 (폭 600px 미만)

- **배치:** 1단. 상단 바(높이 56px)에 제목과 문서 연결 상태, 하단 탭 바는 CMN-01을 따른다.
- **새 회의:** 주 버튼 `lg` 56으로 하단 탭 바 위에 화면 폭 가득 고정하고, 하단 안전 영역만큼 띄운다(CMN-01 3.2, 현행 F09와 같은 위치).
- **검색·필터:** 검색 상자(높이 48px, 글자 16px) 한 줄 아래에 "상세 조건" 칩 하나만 둔다(현행 "상세 조건" 접기 유지). 누르면 하단 시트로 기간(날짜 입력 2개)과 정렬을 연다. 적용된 조건 수를 칩에 표시한다(예: "상세 조건 · 1").
- **처리 실패:** 1건만 펼쳐 보이고 나머지는 "처리 실패 n건 모두 보기"로 접는다(제안). 다시 처리 버튼은 행 안에 항상 표시한다.
- **목록 행:** 2줄 72px. 참석자는 "홍길동 외 3명"처럼 줄여 한 줄을 넘지 않게 한다(제안).
- **보이는 양 (추정):** 360×780 기준 상단 바·검색·하단 고정 버튼·탭 바를 빼면 목록 행 약 5~6건이 보인다.
- **키보드가 열린 상태(`short`, 높이 560px 이하):** 검색 중 상단 바와 여백을 줄이고, 하단 고정 "새 회의" 버튼은 본문 끝으로 옮긴다. 검색 결과 목록이 키보드 위에 보이도록 한다.

### 3.4 PC

- 고려하지 않는다(D-06). 넓은 화면에서는 3.2 태블릿 가로 배치를 본문 최대 폭 1040px로 가운데 정렬한다.
- hover에서만 나타나는 행 동작(예: 마우스를 올리면 보이는 버튼)은 만들지 않는다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 로딩 | 목록 행 골격(제안, 2줄 행 높이 그대로). 현행: "회의 목록을 불러오는 중…" |
| 회의 없음 | 일러스트 + "회의 기록이 없습니다. 회의를 완료하면 여기에 표시됩니다." + 새 회의 버튼 (현행은 문구가 시각적으로 숨겨짐) |
| 검색 결과 없음 | "검색 결과가 없습니다." + 조건 초기화 (제안) |
| 기간 오류 | "시작일은 종료일보다 늦을 수 없습니다. 날짜 범위는 적용하지 않았습니다." |
| 조회 실패 | 오류 카드 + 다시 시도. 이전 목록이 있으면 유지하고 경고만 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 빈 상태가 아이콘만 있어 의미가 약하다. 검색이 Enter·포커스 이동 시에만 적용돼 즉시성이 떨어진다. 메뉴명(회의록)과 화면 제목(회의 기록)이 다르다.
- **제안** — 입력 중 즉시 검색(지연 적용), 터치용 2줄 목록 행(태블릿 가로는 목록 + 필터 2단), 정렬, 처리 중인 회의(진행 상태) 표시 여부 검토.
- **확인 필요** — 필터 단 폭, 처리 실패 3줄 행 높이. D-06(지원 화면 크기)은 태블릿 기준으로 결정됨.
- **확인 필요 (API)** — API-017이 서버 측 검색·페이지 나누기를 지원하는지 확인. 현행은 전체를 받아 화면에서 거르며, 100건 초과 시 이후 회의가 보이지 않을 수 있다.
