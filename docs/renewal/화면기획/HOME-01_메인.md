## 1. 화면 개요

로그인 후 첫 화면이다. 새 회의를 바로 시작하고 최근 회의를 확인한다.

## 3. 화면 구성 요소

화면 기준은 마이크가 있는 태블릿이다. PC 전용 배치는 만들지 않는다(D-06). 공통 틀(내비게이션 레일·상단 바·하단 탭 바)은 [CMN-01](CMN-01_공통레이아웃.md) 3장, 크기·글자·컴포넌트 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 8장을 따른다.

### 3.2 태블릿 가로 (폭 960px 이상)

세로 배치를 그대로 쓰고 본문 최대 폭 1040px로 가운데 정렬한다. 좌우 여백은 32px. 홈은 2단으로 나눌 만큼 내용이 많지 않아 별도 배치를 두지 않는다.

### 3.3 휴대폰 (폭 600px 미만)

- 1단, 상단 바(높이 56px) + 하단 탭 바(높이 64px + 하단 안전 영역). 좌우 여백 16px, 구역 사이 24px.
- 인사 문구는 `headline` 휴대폰 크기(24/32).
- 새 회의 시작 카드는 없애고, "새 회의 시작" 버튼(`lg` 56)을 하단 탭 바 바로 위에 화면 폭 가득 고정한다(CMN-01 3.2). 본문 끝에는 고정 버튼 높이만큼 여백을 둬 마지막 회의 행이 가려지지 않게 한다.
- 처리 실패 배너는 인사 문구 아래에 화면 폭 가득 표시한다.
- 최근 회의는 목록 행 2줄 72px × 3. 360×780 화면 기준으로 상단 바·인사·배너·고정 버튼·탭 바를 빼도 3행이 스크롤 없이 대부분 보인다(추정, 시안에서 확인).
- 문서 연결 상태 칩은 상단 바에 두되 폭이 좁으므로 문구를 짧게 줄인다(예: "연결됨", "점검 필요"). 상태 점만 남기지 않는다(현행 문제 참조).
- 높이가 낮은 화면(`short`, 높이 560px 이하)에서는 고정 버튼을 본문 끝으로 옮긴다.

### 3.4 HOME-01-P01 문서 연결 상태

대화상자 형태는 휴대폰에서 하단 시트(폭 가득, 최대 높이 90%), 태블릿에서 가운데 정렬(최대 폭 560px)이다. 안쪽 여백 24, 모서리 `radius-xl`(20), 그림자 `shadow-overlay`.

| 영역 | 요소 | 내용 |
|---|---|---|
| 머리 | 제목, 닫기 | 문서 연결 상태(`title`) / × 아이콘 버튼 48×48 (Esc·배경 누르기로도 닫힘) |
| 연결 정보 | 서비스 아이콘·이름 | Notion 또는 Confluence |
| | 상태 | "연결됨 · 버전 {n}" / "새 문서 서비스로 전환 중" / "연결 상태를 확인해 주세요". 상태 아이콘 + 문구(색만으로 구분하지 않음) |
| 문서 구조 | 트리 | Meeting Automation › Meetings(회의록), Participants(참석자), Templates(기본 회의록 템플릿). 트리 항목 1줄 목록 행(휴대폰 56 / 태블릿 60) 또는 `body` 글자 목록 (**확인 필요**: 누를 수 없는 표시용이면 행 높이 기준을 적용하지 않아도 됨) |
| 실행 | 문서 연결 변경 | 주 버튼 → `/setup/document`. 버튼 `md`(높이 48), `primary`. 휴대폰 하단 시트에서는 폭 가득, 아래쪽 안전 영역만큼 띄움 |
| 오류 시 | 문구 + 다시 확인 | "연결 상태를 확인할 수 없습니다 / 백엔드 연결을 확인한 뒤 다시 시도해 주세요." `danger-soft` 안내 |
| 연결 없음 | 문구 + 문서 서비스 연결 | "연결된 문서 서비스가 없습니다" |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 최근 회의 로딩 | 목록 행 골격(Skeleton) 3개, 행 높이는 실제 행과 같게(휴대폰 72 / 태블릿 76) (제안). 현행: "회의 목록을 불러오는 중…" |
| 최근 회의 없음 | 일러스트 + "아직 회의 기록이 없습니다. 첫 회의를 시작해 보세요." + 새 회의 버튼 (제안). 휴대폰은 하단 고정 "새 회의 시작" 버튼이 있으므로 빈 상태 안의 버튼은 생략 (제안). 현행: 아이콘만 보이고 문구는 화면에서 숨김 |
| 최근 회의 조회 실패 | 오류 카드 + 다시 시도 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)**
  - 최근 회의가 없을 때 아이콘만 있고 설명 문구가 시각적으로 숨겨져 있어 의미 전달이 약하다.
  - 문서 연결 상태가 작은 아이콘과 점으로만 표시되어 의미를 알기 어렵다.
  - 팝업의 문서 구조 목록에는 Meeting Data가 빠져 있다. 연결 완료 화면(SET-05)은 Meetings, Participants, Meeting Data, Templates 4개를 만든다고 안내한다.
  - 팝업의 "문서 연결 변경"은 `/setup/document`로 이동한다. 코드상 이 경로는 이미 연결된 상태에서 연결 확인 후 다음 단계 버튼이 없어 진행이 막히는 것으로 보인다(추정, 실제 동작 확인 필요). 설정의 변경 흐름(SET-02 → SET-06)으로 연결하는 것이 맞는지 확인이 필요하다.
- **확인 필요** — 요약 지표·처리 실패 배너 포함 여부, 사용자 이름 표시(로그인 정보에 이름이 없으면 이메일 사용)
- **확인 필요 (배치)** — 태블릿 홈에서 상단 바 "+ 새 회의" 버튼과 새 회의 시작 카드의 중복 처리. 최근 회의를 카드 대신 목록 행으로 바꾸는 제안(태블릿 세로 폭 기준). 요약 지표(HOME-01-F06)를 넣으면 놓을 위치는 시안에서 정한다.

Galaxy Tab S9 가로(Chrome, 약 1280×650~710)에서 안내 패널과 새 회의 버튼이 높이를 차지해 최근 회의록이 화면 밖으로 밀렸다. 폭 960 이상·높이 860 이하(`low` 조건)에서는 안내 패널 안에서 그림을 줄여 왼쪽에, 단계·새 회의 버튼을 오른쪽에 두고 따로 있던 버튼 줄을 없앴다. 1280×650에서 최근 회의록까지 스크롤 없이 보인다. 높이가 넉넉한 화면은 그대로다.
