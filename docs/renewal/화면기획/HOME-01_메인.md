# HOME-01 메인

| 항목 | 내용 |
|---|---|
| 화면 ID | HOME-01 |
| 유형 | 페이지 |
| 경로 | `/` |
| 현재 구현 | `frontend/src/MeetingHistory.tsx` `HomePage` |
| 진입 조건 | 로그인(신규) + CMN-04 통과 (문서 연결 READY) |
| 연결 화면 | MTG-01 새 회의, MIN-01 목록, MIN-02 상세, SET-03 문서 연결 변경 |
| 하위 팝업 | HOME-01-P01 문서 연결 상태 |
| 사용 API | API-023 문서 설정 상태, API-017 회의 목록(최근 3건) |
| 현행 캡처 | [메인 화면](<../현_UI/메인 화면.png>) |

## 1. 화면 개요

로그인 후 첫 화면이다. 새 회의를 바로 시작하고 최근 회의를 확인한다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| HOME-01-F01 | 새 회의 시작 | MTG-01 이동 | 주 버튼 |
| HOME-01-F02 | 최근 회의 | 최근 3건 표시 | 제목, 일시, 참석자 이름(최대 3명 + "외 n명"). 클릭 시 MIN-02 |
| HOME-01-F03 | 전체 보기 | MIN-01 이동 | - |
| HOME-01-F04 | 문서 연결 상태 | 상태 표시 + 팝업 | 상태 점 + 서비스 아이콘. 클릭 시 HOME-01-P01 |
| HOME-01-F05 | 처리 중·실패 회의 알림 | 확인이 필요한 회의 안내 | **제안**: 처리 실패 회의(API-033)가 있으면 메인에 배너로 알림 |
| HOME-01-F06 | 요약 지표 | 이번 달 회의 수 등 | **제안**: API-017 결과로 계산 가능한 범위만 (선택) |

### 문서 연결 상태 문구 (현행)

| 조건 | 표시 |
|---|---|
| 조회 중 | 연결 상태 확인 중 |
| 조회 실패 | 연결 상태 확인 필요 |
| 전환 중 (`SWITCHING`) | {서비스} 전환 중 |
| 점검 필요 (`ATTENTION_REQUIRED`) | 연결 점검 필요 |
| 정상 (`READY` + 생성 가능) | {서비스} 연결됨 |
| 연결 있으나 생성 불가 | 문서 설정 확인 필요 |
| 연결 없음 | 문서 서비스 연결 필요 |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안)

```
┌ 상단 바: 홈                              [Notion ● 연결됨] [+ 새 회의] ┐
│                                                                    │
│  안녕하세요, {이름 또는 이메일}님                                        │
│  ┌──────────────────────────────┐  ┌─────────────────────────────┐ │
│  │  🎙  새 회의 시작               │  │ ⚠ 처리 실패 회의 2건          │ │
│  │  녹음하면 회의록을 자동으로 만들어요  │  │   확인하기 →                  │ │
│  │  [ 회의 시작하기 ]               │  └─────────────────────────────┘ │
│  └──────────────────────────────┘                                  │
│                                                                    │
│  최근 회의                                          전체 보기 >        │
│  ┌───────────────┐ ┌───────────────┐ ┌───────────────┐             │
│  │ 주간 회의        │ │ 기획 리뷰        │ │ ...            │             │
│  │ 11월 5일 10:00  │ │ 11월 4일 14:00  │ │                │             │
│  │ 홍길동, 김… 외 2 │ │ ...            │ │                │             │
│  └───────────────┘ └───────────────┘ └───────────────┘             │
└────────────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 인사 | 환영 문구 | 제목 | **제안**. 현행: "회의를 시작할까요?" |
| 주 행동 | 새 회의 시작 카드 | 카드 + 주 버튼 | MTG-01 이동 |
| 알림 | 처리 실패 배너 | 경고 카드 | **제안**. 0건이면 숨김. 클릭 시 MIN-01의 실패 영역 |
| 최근 회의 | 섹션 제목 + 전체 보기 | 제목 + 링크 | MIN-01 |
| | 회의 카드 ×3 | 카드 | 제목(1줄 말줄임), 일시(`yyyy년 m월 d일 HH:mm`), 참석자 요약. 전체가 클릭 영역 |
| 문서 연결 | 상태 칩 | 버튼 | CMN-01 상단 바로 이동(제안) |

### 3.2 HOME-01-P01 문서 연결 상태

| 영역 | 요소 | 내용 |
|---|---|---|
| 머리 | 제목, 닫기 | 문서 연결 상태 / × (Esc·배경 클릭으로도 닫힘) |
| 연결 정보 | 서비스 아이콘·이름 | Notion 또는 Confluence |
| | 상태 | "연결됨 · 버전 {n}" / "새 문서 서비스로 전환 중" / "연결 상태를 확인해 주세요" |
| 문서 구조 | 트리 | Meeting Automation › Meetings(회의록), Participants(참석자), Templates(기본 회의록 템플릿) |
| 실행 | 문서 연결 변경 | 주 버튼 → `/setup/document` |
| 오류 시 | 문구 + 다시 확인 | "연결 상태를 확인할 수 없습니다 / 백엔드 연결을 확인한 뒤 다시 시도해 주세요." |
| 연결 없음 | 문구 + 문서 서비스 연결 | "연결된 문서 서비스가 없습니다" |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 최근 회의 로딩 | 카드 골격(Skeleton) 3개 (제안). 현행: "회의 목록을 불러오는 중…" |
| 최근 회의 없음 | 일러스트 + "아직 회의 기록이 없습니다. 첫 회의를 시작해 보세요." + 새 회의 버튼 (제안). 현행: 아이콘만 보이고 문구는 화면에서 숨김 |
| 최근 회의 조회 실패 | 오류 카드 + 다시 시도 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)**
  - 최근 회의가 없을 때 아이콘만 있고 설명 문구가 시각적으로 숨겨져 있어 의미 전달이 약하다.
  - 문서 연결 상태가 작은 아이콘과 점으로만 표시되어 의미를 알기 어렵다.
  - 팝업의 문서 구조 목록에는 Meeting Data가 빠져 있다. 연결 완료 화면(SET-05)은 Meetings, Participants, Meeting Data, Templates 4개를 만든다고 안내한다.
  - 팝업의 "문서 연결 변경"은 `/setup/document`로 이동한다. 코드상 이 경로는 이미 연결된 상태에서 연결 확인 후 다음 단계 버튼이 없어 진행이 막히는 것으로 보인다(추정, 실제 동작 확인 필요). 설정의 변경 흐름(SET-02 → SET-06)으로 연결하는 것이 맞는지 확인이 필요하다.
- **확인 필요** — 요약 지표·처리 실패 배너 포함 여부, 사용자 이름 표시(로그인 정보에 이름이 없으면 이메일 사용)
