# CMN-03 페이지 없음

| 항목 | 내용 |
|---|---|
| 화면 ID | CMN-03 |
| 유형 | 페이지 |
| 경로 | 정의되지 않은 모든 경로 (`*`) |
| 현재 구현 | `frontend/src/App.tsx` `FutureRouteNotice` |
| 진입 조건 | 없음 (로그인 전이면 AUTH-01 우선, 제안) |
| 연결 화면 | HOME-01, MIN-01 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

잘못된 주소로 들어왔을 때 안내하고 주요 화면으로 돌려보낸다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 |
|---|---|---|
| CMN-03-F01 | 홈 이동 | HOME-01 이동 |
| CMN-03-F02 | 회의록 목록 이동 | MIN-01 이동 |

## 3. 화면 구성 요소

화면 기준은 마이크가 있는 태블릿이다. PC 전용 배치는 만들지 않는다(D-06). 공통 틀은 [CMN-01](CMN-01_공통레이아웃.md) 3장, 크기·글자·컴포넌트 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 8장을 따른다.

### 3.1 태블릿 (기준, 폭 600px 이상)

공통 레이아웃(CMN-01) 안에 표시하는 경우(제안, 4장)의 배치다.

```
┌──────┬──────────────────────────────────────────────┐
│ [로고]│ 페이지 없음                                    │  상단 바 64px
│      ├──────────────────────────────────────────────┤
│  ⌂   │                                              │
│  홈   │          ┌──────────────────────────┐        │
│  ▤   │          │      (일러스트)            │        │
│ 회의록 │          │  PAGE NOT FOUND          │        │  caption
│  👥  │          │  페이지를 찾을 수 없습니다    │        │  headline
│ 참석자 │          │  주소가 잘못되었거나 페이지가  │        │  body
│  ⚙   │          │  이동되었을 수 있습니다.      │        │
│  설정  │          │                          │        │
│      │          │  [     홈으로 이동     ]    │        │  lg 56
│      │          │  [     회의록 목록     ]    │        │  lg 56
│  [👤] │          └──────────────────────────┘        │
└──────┴──────────────────────────────────────────────┘
 레일 88px, 본문 가운데 정렬
```

| 영역 | 요소 | 유형 | 내용 |
|---|---|---|---|
| 본문 카드 | 카드 | 영역 | 본문 가운데 정렬. 테두리 `border`, `radius-lg`, 안쪽 여백 24, 그림자 없음. 카드 최대 폭은 **확인 필요** (제안: 대화상자와 같은 560px) |
| | 일러스트 | 이미지 | **제안**. CMN-02와 같은 톤. 크기는 CMN-02와 같이 **확인 필요** |
| | 보조 제목 | 텍스트 | PAGE NOT FOUND. `caption`, `brand-text` |
| | 제목 | 제목 | 페이지를 찾을 수 없습니다. `headline`(태블릿 28/36) |
| | 설명 | 텍스트 | 주소가 잘못되었거나 페이지가 이동되었을 수 있습니다. `body`, `text-muted` |
| | 홈으로 이동 | 주 버튼 | HOME-01. 버튼 `lg`(높이 56), `primary`, 카드 폭 가득 |
| | 회의록 목록 | 보조 버튼 | MIN-01. 버튼 `lg`(높이 56), `primary-soft`, 카드 폭 가득. 두 버튼 사이 8 이상 |

### 3.2 태블릿 가로 (폭 960px 이상)

세로 배치를 그대로 쓰고 카드를 본문 가운데에 둔다.

### 3.3 휴대폰 (폭 600px 미만)

- 1단, 상단 바(높이 56px) + 하단 탭 바. 카드 테두리 없이 본문 전체를 쓴다. 좌우 여백 16px, 제목은 `headline` 휴대폰 크기(24/32).
- 두 버튼은 하단 탭 바 바로 위에 화면 폭 가득 세로로 쌓아 고정한다(위: 홈으로 이동, 아래: 회의록 목록). 하단 탭 바로도 같은 곳에 갈 수 있으므로 본문 아래에 두는 방안도 가능하다(**확인 필요**).
- 높이가 낮은 화면(`short`, 높이 560px 이하)에서는 일러스트를 숨기고 고정 버튼을 본문 끝으로 옮긴다.

## 4. 리뉴얼 검토 사항

- **제안** — 공통 레이아웃(CMN-01) 안에서 표시해 메뉴(태블릿 내비게이션 레일, 휴대폰 하단 탭 바)로도 이동할 수 있게 한다. 일러스트를 CMN-02와 같은 톤으로 맞춘다.
- **확인 필요** — 본문 카드 최대 폭(제안 560px)과 일러스트 크기는 8장에 기준이 없다. 휴대폰에서 버튼 2개를 탭 바 위에 고정할지, 본문 아래에 둘지.
