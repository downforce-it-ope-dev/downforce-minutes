# CMN-03 페이지 없음

| 항목 | 내용 |
|---|---|
| 화면 ID | CMN-03 |
| 유형 | 페이지 |
| 경로 | 정의되지 않은 모든 경로 (`*`) |
| 현재 구현 | `frontend/src/App.tsx` `FutureRouteNotice` |
| 진입 조건 | 없음 (로그인 전이면 AUTH-01 우선, 제안) |
| 연결 화면 | HOME-01, MIN-01 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

잘못된 주소로 들어왔을 때 안내하고 주요 화면으로 돌려보낸다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 |
|---|---|---|
| CMN-03-F01 | 홈 이동 | HOME-01 이동 |
| CMN-03-F02 | 회의록 목록 이동 | MIN-01 이동 |

## 3. 화면 구성 요소

| 영역 | 요소 | 유형 | 내용 |
|---|---|---|---|
| 본문 카드 | 보조 제목 | 텍스트 | PAGE NOT FOUND |
| | 제목 | 제목 | 페이지를 찾을 수 없습니다 |
| | 설명 | 텍스트 | 주소가 잘못되었거나 페이지가 이동되었을 수 있습니다. |
| | 홈으로 이동 | 주 버튼 | HOME-01 |
| | 회의록 목록 | 보조 버튼 | MIN-01 |

## 4. 리뉴얼 검토 사항

- **제안** — 공통 레이아웃(CMN-01) 안에서 표시해 메뉴로도 이동할 수 있게 한다. 일러스트를 CMN-02와 같은 톤으로 맞춘다.
