# SET-02 문서 연결 관리

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-02 |
| 유형 | 페이지 |
| 경로 | `/settings/document` (문서 연결 `READY` 상태) |
| 현재 구현 | `frontend/src/DocumentSetupWizard.tsx` (`settings` 모드, 변경 전 상태) |
| 진입 조건 | 로그인(신규). SET-01 "문서 연결 설정", CMN-04 실패 화면, `STORAGE_UNAVAILABLE` 시 이동 |
| 연결 화면 | 설정으로 돌아가기 → SET-01 / 문서 서비스 변경 → SET-03(변경 모드) / 이전 화면으로 돌아가기(회의 화면에서 온 경우) |
| 사용 API | API-023 문서 설정 상태, API-001·API-003 (연결 직후 데이터 확인) |
| 현행 캡처 | [설정-문서 연결](<../현_UI/설정-문서 연결.png>) |

## 1. 화면 개요

현재 연결된 문서 서비스와 저장 위치를 확인하고, 다른 서비스로 바꾸는 흐름을 시작한다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-02-F01 | 연결 정보 | 서비스 아이콘·이름, 설명, 상태 배지 | "회의록과 기본 템플릿이 저장되는 서비스입니다.", "연결됨" |
| SET-02-F02 | 연결된 문서 열기 | 루트 페이지를 새 탭으로 | `rootUrl` |
| SET-02-F03 | 문서 서비스 변경 | 변경 흐름 시작 | 입력값·이전 결과 초기화 후 SET-03(변경 모드) |
| SET-02-F04 | 설정으로 돌아가기 | SET-01 | - |
| SET-02-F05 | 이전 화면으로 돌아가기 | 회의 화면에서 온 경우 | 내부 `/meetings/...` 경로만 허용 |
| SET-02-F06 | 연결 데이터 다시 확인 | 연결 직후 설정·참석자 조회 실패 시 | 재시도 버튼 |
| SET-02-F07 | 문서 구조 표시 | 생성된 페이지 구조 | **제안**: Meetings, Participants, Meeting Data, Templates |

## 3. 화면 구성 요소

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 | 설정으로 돌아가기 | 링크 | SET-01 |
| | 제목 + 설명 | 제목 | 문서 연결 / 현재 연결된 문서 서비스와 저장 위치를 확인합니다. |
| 연결 카드 | 서비스 아이콘 | 이미지 | Notion / Confluence |
| | 서비스 이름 + 설명 | 텍스트 | - |
| | 상태 배지 | 배지 | 연결됨 |
| | 연결된 문서 열기 ↗ | 보조 버튼(외부 링크) | 새 탭 |
| | 문서 구조 | 트리 | **제안** |
| | 연결 정보 | 텍스트 | **제안**: 연결 버전, 연결 일시(응답에 있을 경우) |
| 메시지 | 오류 / 안내 | 텍스트 | - |
| 실행 | 문서 서비스 변경 | 주 버튼 → 제안: 보조 또는 위험 스타일 | 변경은 자료 이전을 수반하므로 신중한 행동으로 표현 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 정상 | 연결 카드 + 변경 버튼 |
| 저장소 사용 불가 | "저장소 설정을 확인할 수 없습니다 / 문서 설정 저장소가 준비되지 않아 문서 기능을 사용할 수 없습니다. 관리자에게 저장소 설정을 확인해 달라고 요청해 주세요." + 다시 확인 |
| 조회 실패 | "문서 연결 상태를 확인할 수 없습니다" + 다시 불러오기 |
| 진행 중 작업 있음 | SET-05 표시 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 화면이 거의 비어 있고 정보가 서비스 이름뿐이다. 문서 서비스 변경이 가장 눈에 띄는 주 버튼이라 위험한 작업이 주 행동처럼 보인다(캡처).
- **제안** — SET-01의 문서 연결 섹션 안으로 합치는 방안 검토(별도 페이지 대신 상세 패널).
- **확인 필요** — D-05: 관리자 전용 여부.
