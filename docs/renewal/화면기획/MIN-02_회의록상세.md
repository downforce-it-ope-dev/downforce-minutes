# MIN-02 회의록 상세

| 항목 | 내용 |
|---|---|
| 화면 ID | MIN-02 |
| 유형 | 페이지 (읽기 전용) |
| 경로 | `/meetings/:documentId` |
| 현재 구현 | `frontend/src/MeetingDetailPage.tsx`, `components/MeetingListBackLink.tsx` |
| 진입 조건 | 로그인(신규). MIN-01·HOME-01 행 클릭, MTG-05 "저장된 회의록 보기" |
| 연결 화면 | 목록으로 → MIN-01 |
| 하위 팝업 | MIN-02-P01 전사 원문 |
| 사용 API | API-018 회의 상세 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

문서 서비스에 저장된 회의록을 읽는다. 편집은 하지 않는다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MIN-02-F01 | 회의 정보 | 제목, 일시, 참석자 이름 | 날짜만 있는 값은 날짜만, 시각이 있으면 날짜+시각 |
| MIN-02-F02 | 회의록 본문 | 요약, 논의 사항, 결정 사항, 실행 항목, 후속 조치 | 내용이 없는 섹션은 숨김. 요약이 없으면 "요약이 없습니다." |
| MIN-02-F03 | 실행 항목 | 할 일 · 담당 · 기한 | 담당자는 참석자 이름으로 표시 |
| MIN-02-F04 | 전사 원문 보기 | MIN-02-P01 | - |
| MIN-02-F05 | 목록으로 | MIN-01 이동 | - |
| MIN-02-F06 | 원본 문서 열기 | Notion·Confluence 원문 | **제안**. API-018 응답에 문서 URL이 있는지 확인 필요 |
| MIN-02-F07 | 복사·공유 | 회의록 텍스트 복사 | **제안** (선택) |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안)

```
┌ 상단 바: ← 회의록 목록                                [원본 문서 열기 ↗] ┐
│ 주간 회의                                                          │
│ 2026년 11월 5일 오전 10:00 · 참석자 홍길동, 김철수, 이영희               │
│ ┌ 회의록 (좌) ─────────────────────────┐ ┌ 목차 / 전사 원문 (우) ────┐ │
│ │ 요약                                 │ │ · 요약                    │ │
│ │ ...                                  │ │ · 논의 사항               │ │
│ │ 논의 사항 · 결정 사항 · 실행 항목(표)     │ │ · 결정 사항               │ │
│ │ 후속 조치                             │ │ · 실행 항목               │ │
│ └─────────────────────────────────────┘ │ [전사 원문 보기]           │ │
│                                         └──────────────────────────┘ │
└────────────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 | 목록으로 | 링크 | MIN-01 |
| 머리 | 제목 | 제목(h1) | 회의 제목 |
| | 일시·참석자 | 텍스트 | 참석자 없으면 "참석자 정보 없음" |
| 본문 | 요약 | 섹션 | - |
| | 논의 사항 / 결정 사항 / 후속 조치 | 섹션 + 목록 | 비어 있으면 숨김 |
| | 실행 항목 | 섹션 + 표(제안) | 할 일, 담당, 기한 |
| 보조 | 전사 원문 보기 | 보조 버튼 | MIN-02-P01 |

### 3.2 MIN-02-P01 전사 원문 (드로어)

| 요소 | 내용 |
|---|---|
| 제목 | 현행 "Transcript" → "전사 원문"으로 통일 (제안, MTG-04-P01과 동일) |
| 항목 | 화자 이름(참석자 이름 또는 화자 ID), 시작 시각 mm:ss, 발화 |
| 빈 상태 | Transcript가 없습니다. |
| 닫기 | ×, Esc, 배경 클릭 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 로딩 | "회의 상세를 불러오는 중…" (제안: 본문 골격) |
| 없음 | "회의 기록을 찾을 수 없습니다. 삭제되었거나 더 이상 접근할 수 없는 회의입니다." |
| 조회 실패 | 오류 카드 + 다시 시도 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 같은 항목의 이름이 검토 화면(MTG-04)과 다르다: 논의 내용↔논의 사항, Transcript↔전사 원문. 회의록 본문과 전사 원문을 같이 볼 수 없다.
- **제안** — 문서형 읽기 레이아웃(본문 폭 720px 내외), 섹션 목차, 실행 항목 표, 전사 원문 우측 패널.
- **확인 필요** — 저장 후 회의록 수정 기능이 필요한지(현재 Backend는 저장된 회의록 편집 API 없음 — 신규 기능이면 Backend 변경 필요).
