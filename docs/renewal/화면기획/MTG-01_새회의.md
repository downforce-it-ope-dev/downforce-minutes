# MTG-01 새 회의

| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-01 |
| 유형 | 페이지 (입력 폼) |
| 경로 | `/meetings/new` |
| 현재 구현 | `frontend/src/NewMeetingPage.tsx`, `MeetingParticipantSelector.tsx`, `App.tsx` `NewMeetingRoute` |
| 진입 조건 | 로그인(신규) + CMN-04 통과 |
| 연결 화면 | 시작 성공 → MTG-02 / 참석자 없음 → PTC-01 / MTG-02에서 돌아오면 입력값 복원 |
| 사용 API | API-001 앱 설정, API-002 템플릿 목록, API-003 참석자 목록, API-006 회의 세션 생성 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

회의 제목, 날짜, 회의록 템플릿, 참석자를 정하고 녹음 세션을 만든다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MTG-01-F01 | 회의 제목 입력 | 필수 | 앞뒤 공백 제거 후 비어 있으면 오류 |
| MTG-01-F02 | 회의 날짜 선택 | 필수, 기본값 오늘(브라우저 기준) | 날짜 선택기 |
| MTG-01-F03 | 회의록 템플릿 선택 | 필수, 기본 `default.md` | 목록은 API-002. 현재 기본 제공 `default.md`, `project.md` |
| MTG-01-F04 | 참석자 선택 | 1명 이상 필수 | 펼침 목록에서 체크박스 다중 선택, 이름·이메일 표시. "n명 선택됨" |
| MTG-01-F05 | 문서 연결 확인 | 문서 연결이 준비됐는지 확인 | API-001의 `setup.status = READY`, `canCreateMeeting`, `connectionVersion ≥ 1`, 회사 시간대 필요 |
| MTG-01-F06 | 회의 시작 | 세션 생성 후 MTG-02 이동 | 제출 중 중복 클릭 방지. 같은 입력의 재시도는 같은 멱등 키 사용 |
| MTG-01-F07 | 연결 변경 감지 | 제출 중 문서 연결이 바뀐 경우 | 설정과 참석자를 다시 불러오고 선택을 초기화한 뒤 안내 |
| MTG-01-F08 | 입력값 복원 | 녹음 화면에서 "회의 준비로 돌아가기" 시 | 제목·날짜·템플릿·참석자 복원 |
| MTG-01-F09 | 참석자 빠른 추가 | 목록에 없는 참석자 추가 | **제안**: 선택 목록 하단 "+ 새 참석자" → PTC-01-P01 팝업 재사용 |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안)

```
┌ 상단 바: ← 새 회의 ───────────────────────────────────────────┐
│ ┌ 회의 정보 ─────────────────────┐  ┌ 요약 ──────────────────┐ │
│ │ 회의 제목 *                     │  │ 주간 회의               │ │
│ │ [                         ]    │  │ 2026-11-05 · 기본 템플릿 │ │
│ │ 회의 날짜 *     회의록 템플릿 *   │  │ 참석자 3명               │ │
│ │ [2026-11-05]   [기본 회의록 ▾]   │  │                        │ │
│ ├ 참석자 * ──────────────────────┤  │ 문서 저장: Notion ●     │ │
│ │ [🔍 이름·이메일 검색          ]  │  │                        │ │
│ │ ☑ 홍길동  hong@…               │  │ [   회의 시작   ]       │ │
│ │ ☐ 김철수  kim@…                │  └───────────────────────┘ │
│ │ 선택됨: [홍길동 ×] [이영희 ×]     │                            │
│ └───────────────────────────────┘                            │
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 | 필수 |
|---|---|---|---|---|
| 상단 | 제목, 뒤로 가기 | 제목 | 새 회의 | - |
| 회의 정보 | 회의 제목 | 텍스트 입력 | 최대 길이 확인 필요(Backend 검증 기준) | 필수 |
| | 회의 날짜 | 날짜 입력 | 기본 오늘 | 필수 |
| | 회의록 템플릿 | 선택 상자 | 템플릿 이름 표시. **제안**: 선택 시 템플릿 구성(섹션) 미리보기 | 필수 |
| 참석자 | 검색 | 검색 입력 | **제안**. 현행은 검색 없이 전체 목록 | - |
| | 참석자 목록 | 체크박스 목록 | 이름 + 이메일 | 1명 이상 |
| | 선택된 참석자 | 칩 목록 | **제안**. 칩의 ×로 해제 | - |
| | 참석자 없음 안내 | 빈 상태 | "참석자가 없습니다." + 참석자 관리 링크 | - |
| 요약 | 입력 요약 | 카드 | **제안**: 데스크톱 우측 고정 | - |
| | 문서 저장 위치 | 상태 | 연결된 서비스와 상태 | - |
| 실행 | 회의 시작 | 주 버튼 | 로딩·사용 불가 상태에서 비활성. 제출 중 "회의 시작 중…" | - |
| | 오류 메시지 | 텍스트 | 버튼 위 | - |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 초기 로딩 | 각 영역 로딩 표시 (설정·템플릿·참석자를 각각 불러옴) |
| 일부 조회 실패 | 해당 영역에 오류 + 영역별 다시 시도 버튼. 이전 데이터가 있으면 유지하고 경고만 표시 |
| 템플릿 없음 | "사용 가능한 Template이 없습니다." — 시작 불가 |
| 참석자 없음 | "참석자가 없습니다." + 참석자 관리 링크 — 시작 불가 |
| 문서 연결 미완료 | "문서 서비스 연결 설정을 완료한 뒤 회의를 시작할 수 있습니다." — 시작 불가 |
| 필수값 누락 | 각 입력 아래 오류 (제출 시점에 표시) |
| 제출 중 | 버튼 로딩 |
| 연결 변경 | "문서 연결이 바뀌었습니다. 설정과 참석자 목록을 새로 확인했습니다. 내용을 확인한 뒤 다시 시작해 주세요." |

## 5. 메시지 (현행)

| 구분 | 문구 |
|---|---|
| 제목 누락 | 회의 제목을 입력해 주세요. |
| 날짜 누락 | 회의 날짜를 선택해 주세요. |
| 템플릿 누락 | 회의록을 선택해 주세요. |
| 참석자 누락 | 참석자를 한 명 이상 추가해 주세요. |
| 시작 실패 | 회의를 시작하지 못했습니다. 연결을 확인한 뒤 다시 시도해 주세요. |

## 6. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 참석자가 많아지면 검색 없이 체크박스 목록만 길어진다. 템플릿 선택 라벨이 "회의록 선택"으로 되어 있어 의미가 모호하다. 마이크 사전 점검이 다음 화면에서야 이루어진다.
- **제안** — 2단 구성(입력 + 요약), 참석자 검색·칩, 템플릿 미리보기, 마이크 권한 사전 안내 문구.
- **확인 필요** — 템플릿 미리보기에 필요한 템플릿 본문을 API-002가 주는지 확인(현재 응답 필드 미검증). 참석자 빠른 추가 포함 여부.
