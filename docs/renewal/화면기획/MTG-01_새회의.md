# MTG-01 새 회의

| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-01 |
| 유형 | 페이지 (입력 폼) |
| 경로 | `/meetings/new` |
| 현재 구현 | `frontend/src/NewMeetingPage.tsx`, `MeetingParticipantSelector.tsx`, `App.tsx` `NewMeetingRoute` |
| 진입 조건 | 로그인(신규) + CMN-04 통과 |
| 연결 화면 | 시작 성공 → MTG-02 / 참석자 없음 → PTC-01 / MTG-02에서 돌아오면 입력값 복원 |
| 사용 API | API-001 앱 설정, API-002 템플릿 목록, API-003 참석자 목록, API-006 회의 세션 생성 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

회의 제목, 날짜, 회의록 템플릿, 참석자를 정하고 녹음 세션을 만든다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MTG-01-F01 | 회의 제목 입력 | 필수 | 앞뒤 공백 제거 후 비어 있으면 오류 |
| MTG-01-F02 | 회의 날짜 선택 | 필수, 기본값 오늘(브라우저 기준) | 날짜 선택기 |
| MTG-01-F03 | 회의록 템플릿 선택 | 필수, 기본 `default.md` | 목록은 API-002. 현재 기본 제공 `default.md`, `project.md` |
| MTG-01-F04 | 참석자 선택 | 1명 이상 필수 | 펼침 목록에서 체크박스 다중 선택, 이름·이메일 표시. "n명 선택됨" |
| MTG-01-F05 | 문서 연결 확인 | 문서 연결이 준비됐는지 확인 | API-001의 `setup.status = READY`, `canCreateMeeting`, `connectionVersion ≥ 1`, 회사 시간대 필요 |
| MTG-01-F06 | 회의 시작 | 세션 생성 후 MTG-02 이동 | 제출 중 중복 클릭 방지. 같은 입력의 재시도는 같은 멱등 키 사용 |
| MTG-01-F07 | 연결 변경 감지 | 제출 중 문서 연결이 바뀐 경우 | 설정과 참석자를 다시 불러오고 선택을 초기화한 뒤 안내 |
| MTG-01-F08 | 입력값 복원 | 녹음 화면에서 "회의 준비로 돌아가기" 시 | 제목·날짜·템플릿·참석자 복원 |
| MTG-01-F09 | 참석자 빠른 추가 | 목록에 없는 참석자 추가 | **제안**: 선택 목록 하단 "+ 새 참석자" → PTC-01-P01 팝업 재사용 |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4절·8장을 따른다. 이 화면은 집중 모드가 아니므로 태블릿은 내비게이션 레일, 휴대폰은 하단 탭 바를 표시한다(CMN-01). 회의 직전에 태블릿을 들고 빠르게 입력하는 장면을 기준으로 한다.

### 3.1 태블릿 (기준, 600px 이상)

태블릿 세로(폭 820px 전후) 기준. 레일 오른쪽 본문을 1단 폼으로 두고, 회의 시작 버튼과 짧은 요약은 화면 아래에 고정한다(**제안**).

```
┌──────┬ 상단 바 64px: ← 새 회의 ──────────────────────────────┐
│ [로고]│                                                     │
│      │  회의 정보                                    title   │
│  ⌂   │  회의 제목 *                                          │
│  홈   │  [                                         ] 52px   │
│  ▤   │  회의 날짜 *                 회의록 템플릿 *              │
│ 회의록 │  [2026-11-05        📅]     [기본 회의록          ▾]   │
│  👥  │                              템플릿 구성 보기 (제안)     │
│ 참석자 │  참석자 *                              3명 선택됨       │
│  ⚙   │  [🔍 이름·이메일 검색                        ] 52px    │
│  설정  │  선택됨: [홍길동 ×] [이영희 ×] [박민수 ×]                │
│      │  ┌─────────────────────────────────────────────┐   │
│      │  │ ☑ 홍길동                                       │ 76 │
│      │  │   hong@…                                     │   │
│      │  │ ☐ 김철수                                       │   │
│      │  │   kim@…                                      │   │
│      │  │ + 새 참석자 (제안)                               │   │
│      │  └─────────────────────────────────────────────┘   │
│      ├─────────────────────────────────────────────────────┤
│  [👤] │  주간 회의 · 기본 회의록 · 3명    [    회의 시작    ] 56 │  하단 고정
└──────┴─────────────────────────────────────────────────────┘
 레일 88px
```

| 영역 | 요소 | 유형 | 내용·규칙 | 필수 |
|---|---|---|---|---|
| 상단 바 (높이 64) | 제목, 뒤로 가기 | 제목 | 새 회의. `headline` 28/36, 뒤로 가기 아이콘 버튼 48×48 | - |
| 회의 정보 | 구역 제목 | 제목 | `title` 20/28 | - |
| | 회의 제목 | 텍스트 입력 | 높이 52, 글자 `body` 16, 이름표 `label`, 오류는 아래 `caption` + `danger-soft` 글자색(red-700). 최대 길이 확인 필요(Backend 검증 기준) | 필수 |
| | 회의 날짜 | 날짜 입력 | 높이 52. 기본 오늘. 터치 기기 기본 날짜 선택기 사용 여부 **확인 필요**(현행은 브라우저 날짜 입력) | 필수 |
| | 회의록 템플릿 | 선택 상자 | 높이 52. 템플릿 이름 표시. 태블릿 세로에서는 날짜와 한 줄에 2칸. **제안**: 선택 시 템플릿 구성(섹션) 미리보기 — 가운데 대화상자(최대 폭 560) | 필수 |
| 참석자 | 검색 | 검색 입력 | **제안**. 높이 52, 글자 16. 현행은 검색 없이 전체 목록 | - |
| | 참석자 목록 | 체크박스 목록 | 이름 + 이메일 2줄 목록 행(높이 76). 체크박스 표시 22. **행 전체가 누르는 영역**이며 누르면 선택이 바뀐다(hover 상태 없음). 선택된 행은 `selected`(lavender-100 배경 + lavender-800 글자) + 체크 표시. 현행: 펼침 목록 + 체크박스 다중 선택 | 1명 이상 |
| | 선택 수 | 텍스트 | "n명 선택됨"(현행). `caption` | - |
| | 선택된 참석자 | 칩 목록 | **제안**. 칩의 ×로 해제. 칩은 `radius-full`, 배경 `selected`. 칩 높이는 8.5에 정의 없음 → **확인 필요**(제안: 보이는 높이 40, × 누르는 영역 48×48) | - |
| | 새 참석자 | 목록 행 버튼 | **제안**(MTG-01-F09). 목록 마지막 행. PTC-01-P01을 가운데 대화상자로 띄움 | - |
| | 참석자 없음 안내 | 빈 상태 | "참석자가 없습니다." + 참석자 관리 링크(`primary-hover` 글자색, 누르는 영역 48) | - |
| 하단 고정 영역 | 입력 요약 | 텍스트 | **제안**: 제목 · 템플릿 · 참석자 수 1줄 `caption`, `text-muted`. 문서 저장 위치는 공통 상단 바의 문서 연결 상태(CMN-01-F06)로 대신한다 | - |
| | 회의 시작 | 주 버튼 `lg` | 높이 56, `primary`. 로딩·사용 불가 상태에서 비활성. 제출 중 "회의 시작 중…". 하단 안전 영역만큼 띄움 | - |
| | 오류 메시지 | 텍스트 | 버튼 위, `danger-soft` | - |

- **마이크 사전 안내 (제안):** 회의 시작 버튼 위에 "다음 화면에서 마이크 권한을 요청합니다" 안내를 `caption`으로 둔다. 태블릿 마이크로 녹음하는 것이 기본이므로 권한 요청을 미리 알린다.

### 3.2 태블릿 가로 (960px 이상)

왼쪽에 입력 폼, 오른쪽에 요약 카드를 둔다(**제안**). 본문 최대 폭 1040px, 좌우 여백 32px. 하단 고정 영역은 없애고 회의 시작 버튼을 요약 카드 안으로 옮긴다.

```
┌──────┬ 상단 바 64px: ← 새 회의 ───────────────────────────────────────────────┐
│ [로고]│ ┌ 회의 정보 ──────────────────────────┐  ┌ 요약 (카드, 위에 고정) ────────┐ │
│  ⌂   │ │ 회의 제목 *                          │  │ 주간 회의              title  │ │
│  홈   │ │ [                              ]    │  │ 2026-11-05 · 기본 회의록       │ │
│  ▤   │ │ 회의 날짜 *        회의록 템플릿 *      │  │ 참석자 3명                    │ │
│ 회의록 │ │ [2026-11-05 📅]   [기본 회의록 ▾]     │  │ 문서 저장: Notion ●           │ │
│  👥  │ ├ 참석자 * ───────────────────────────┤  │                             │ │
│ 참석자 │ │ [🔍 이름·이메일 검색             ]    │  │ 다음 화면에서 마이크 권한을      │ │
│  ⚙   │ │ 선택됨: [홍길동 ×] [이영희 ×]           │  │ 요청합니다 (제안)              │ │
│  설정  │ │ ☑ 홍길동  hong@…                    │  │                             │ │
│      │ │ ☐ 김철수  kim@…                     │  │ [       회의 시작       ] 56  │ │
│  [👤] │ └────────────────────────────────────┘  └─────────────────────────────┘ │
└──────┴────────────────────────────────────────────────────────────────────────┘
```

- 폼은 약 60%, 요약 카드는 약 40%. 요약 카드는 안쪽 여백 24, 테두리 neutral-200, 그림자 없음(8.4). 폼을 스크롤해도 요약 카드는 위에 붙어 있다(제안).
- 참석자 행은 폭이 넓으므로 이름과 이메일을 한 줄로 둔다(1줄 행 60).

### 3.3 휴대폰 (600px 미만)

1단. 상단 바 56px, 좌우 여백 16px. 하단 탭 바(64 + 안전 영역)를 표시하고, 회의 시작 버튼을 탭 바 바로 위에 화면 폭 가득 고정한다(CMN-01 3.2).

```
┌ 상단 바 56px: ← 새 회의 ─────────┐
│ 회의 제목 *                      │
│ [                        ] 48  │
│ 회의 날짜 *                      │
│ [2026-11-05          📅]       │
│ 회의록 템플릿 *                   │
│ [기본 회의록              ▾]     │
│ 참석자 *            3명 선택됨    │
│ [🔍 이름·이메일 검색        ]     │
│ [홍길동 ×] [이영희 ×]             │
│ ☑ 홍길동                     72 │
│   hong@…                       │
│ ☐ 김철수                        │
├────────────────────────────────┤
│ [         회의 시작          ] 56│  하단 고정, 폭 가득
├────────────────────────────────┤
│  ⌂ 홈   ▤ 회의록  👥 참석자  ⚙ 설정 │  하단 탭 바 64 + 안전 영역
└────────────────────────────────┘
```

- 입력란 높이 48, 글자 16(Safari 자동 확대 방지). 날짜와 템플릿은 한 줄에 하나씩 쌓는다.
- 참석자 행은 2줄 72. 행 전체를 눌러 선택한다.
- 템플릿 구성 미리보기(제안)와 새 참석자 추가(PTC-01-P01, 제안)는 하단 시트로 띄운다(최대 높이 90%, `radius-xl` 20).
- 요약 카드는 두지 않는다. 필요한 정보는 각 입력란에 이미 보이므로 버튼 위 요약 줄도 생략한다(제안).
- **화면 키보드:** 제목·검색 입력에 초점이 가면 해당 입력란이 키보드에 가리지 않도록 보이는 영역 안으로 스크롤한다. 키보드가 열려 높이가 560px 이하(`short`)가 되면 고정된 회의 시작 버튼을 본문 끝으로 옮겨 입력 영역을 가리지 않게 한다.
- **엄지 범위:** 주 동작(회의 시작)만 하단에 두고, 뒤로 가기는 상단에 둔다. 참석자 목록이 길어도 회의 시작 버튼은 항상 보인다(`short` 제외).

### 3.4 공통 터치 규칙

- hover로만 보이는 요소(참석자 이메일 툴팁, hover 시 나타나는 × 등)는 만들지 않는다. 이메일과 해제 ×는 항상 보인다.
- 누르는 대상은 48×48 이상, 서로 8px 이상 띄운다(8.5).

## 6. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 참석자가 많아지면 검색 없이 체크박스 목록만 길어진다. 템플릿 선택 라벨이 "회의록 선택"으로 되어 있어 의미가 모호하다. 마이크 사전 점검이 다음 화면에서야 이루어진다.
- **제안** — 태블릿 세로는 1단 폼 + 하단 고정 회의 시작, 태블릿 가로(960px 이상)는 2단 구성(입력 + 요약), 휴대폰은 1단 + 탭 바 위 고정 버튼. 참석자 검색·칩, 행 전체 터치 선택, 템플릿 미리보기, 마이크 권한 사전 안내 문구.
- **결정** — D-06: 마이크가 있는 태블릿 기준, 휴대폰까지 지원, PC는 고려하지 않음(2026-11-06).
- **확인 필요** — 템플릿 미리보기에 필요한 템플릿 본문을 API-002가 주는지 확인(현재 응답 필드 미검증). 참석자 빠른 추가 포함 여부. 참석자 칩 크기(8.5에 정의 없음). 터치 기기에서 날짜 입력에 기기 기본 날짜 선택기를 쓸지 여부.
