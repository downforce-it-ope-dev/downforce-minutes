# SET-06 문서 서비스 전환 (자료 이전 방식 선택)

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-06 |
| 유형 | 페이지 (변경 마법사 단계) |
| 경로 | `/settings/document` (변경 모드) |
| 현재 구현 | `frontend/src/DocumentSetupWizard.tsx` (대상 준비 완료 `PREPARED` 상태) |
| 진입 조건 | 이미 연결된 상태에서 SET-04 연결 확인 → 대상 구조 준비 완료 |
| 연결 화면 | 전환 시작 → SET-05 (SWITCH 진행) → 완료 시 확인 → HOME-01 |
| 사용 API | API-028 전환 시작, API-027 작업 상태, API-029 재개, API-030 취소 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

새 문서 서비스로 바꿀 때 기존 자료(참석자, 회의록)를 옮길지 정하고 전환을 시작한다. 원본 자료는 원래 서비스에 그대로 남는다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-06-F01 | 대상 표시 | 전환할 서비스 | 대상 연결: Notion / Confluence Cloud |
| SET-06-F02 | 이전 범위 안내 | 복사 대상과 제외 대상 | 참석자, 회의록의 Transcript·Minutes·참석자 참조를 복사. 첨부·댓글·버전 이력 제외. 이메일 재발송 없음 |
| SET-06-F03 | 이전 방식 선택 | 전체 복사 / 빈 구조로 새 시작 | 기본: 전체 복사 |
| SET-06-F04 | 빈 구조 확인 | 빈 구조 선택 시 | "기존 자료가 새 서비스 목록에 나타나지 않음을 확인했습니다. 자료는 원본에 보존됩니다." 체크해야 진행 |
| SET-06-F05 | 전환 시작 | 서버에 전환 요청 | 시작 중 "전환 시작 중…". 성공 Toast "문서 서비스 변경을 시작했습니다." → SET-05 |
| SET-06-F06 | 결과 불명확 처리 | 요청 결과 모름 | "변경 요청 결과를 확인해 주세요…" 새 요청 전에 상태 확인 |
| SET-06-F07 | 동시 변경 처리 | 412 | 최신 상태로 다시 연결 확인 안내 |

### 전환 진행 중 안내 (현행, SET-05에 표시)

| 상태 | 안내 |
|---|---|
| 진행 중 | 전환 완료 전까지 원본 연결이 유지됩니다. 작업 재개와 취소는 서버가 허용한 경우에만 가능합니다. |
| 취소 요청됨 | 취소를 요청했습니다. 안전한 중단 지점에서 멈출 때까지 진행 상태를 확인해 주세요. |
| 완료 | 새 문서 서비스로 전환했습니다. 원본 자료는 원본 서비스에 보존됩니다. |
| 취소됨 | 변경을 취소했습니다. 원본 연결이 활성 상태이며 부분 복사본은 대상에 보존됩니다. |
| 확인 필요 | Provider 생성 결과가 불명확합니다. 대상 구조를 확인해 주세요. 자동 재시도하지 않습니다. |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4·8장을 따른다. 변경 마법사 단계이므로 CMN-01 "집중 모드"(메뉴 숨김, 상단 바 제목만)로 표시한다. 단계 표시와 마법사 열 폭은 SET-03 3.1·3.2를 따른다.

### 3.1 태블릿 (기준, 600px 이상)

가운데 1단 배치다.

```
┌ 문서 서비스 변경 ─────────────────────────────────────────┐
│ ① 서비스 선택 ✓ ─ ② 연결 정보 ✓ ─ ③ 자료 이전 ● ─ ④ 전환      │
│                                                       │
│  Notion  ──────────▶  Confluence Cloud                 │
│  (현재, 원본 보존)          (새 연결)                       │
│                                                       │
│  ◉ 전체 복사 (권장)                                      │
│    참석자 n명, 회의록 n건을 새 서비스로 복사합니다.            │
│  ○ 빈 구조로 새 시작                                      │
│    ☐ 기존 자료가 새 목록에 나타나지 않음을 확인했습니다.        │
│                                                       │
│  복사 제외: 첨부, 댓글, 버전 이력 · 이메일 재발송 없음          │
│                                                       │
│  [취소]                              [문서 서비스 전환]    │
└───────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 머리 | 제목 | 제목 | 자료 이전 방식. 상단 바 64px(제목만), `headline` |
| | 단계 표시 | 단계 표시기 | **제안**. ③ 자료 이전 강조 (SET-03 3.1) |
| 대상 | 현재 → 새 서비스 | 시각 요소 | **제안**: 원본 보존을 시각적으로 표시. 현행은 "대상 연결: …" 텍스트. 서비스 이름 `title`, 보조 문구 `caption`·`text-muted`. 새 연결 쪽은 `selected` 면(보라 계열)으로 구분하고 "새 연결" 문구를 함께 쓴다 |
| 안내 | 이전 범위 | 텍스트 | F02. 복사 제외·재발송 없음 안내는 `warning-soft` 안내 상자 + 아이콘(제안) |
| 선택 | 이전 방식 | 라디오 그룹 | 전체 복사 / 빈 구조로 새 시작. 라디오 표시 22, 행 높이 48 이상(설명 줄이 붙으면 그만큼 늘어남), 행 전체가 누르는 영역. 선택된 행은 `selected` 배경(제안) |
| | 빈 구조 확인 | 체크박스 | 빈 구조 선택 시만. 체크박스 표시 22, 행 높이 48, 문구 전체를 눌러도 체크 |
| | 이전 예상 건수 | 텍스트 | **제안** — 전환 전 건수 조회 API는 확인 필요. 숫자는 고정폭 숫자 |
| 실행 | 문서 서비스 전환 | 주 버튼 `lg` 56 | 빈 구조 + 미확인이면 비활성. `primary`. 비활성은 neutral-400 이하 색 + 비활성 이유 문구(7.4 사용 규칙) |
| | 취소 | 보조 버튼 `md` 48 | **제안**. 현행은 하단 "문서 서비스 설정으로 돌아가기" 링크. 전환 버튼과 8px 이상 띄움 |
| 오류 | 시작 실패·불명확 | 안내 상자 | `danger-soft`(실패), `warning-soft`(결과 불명확) + 아이콘 |
| 최종 확인 (제안, 5장) | 대화상자 | 확인 팝업 | 휴대폰 하단 시트 / 태블릿 가운데 최대 560px. 안쪽 여백 24, `radius-xl`. 버튼: 취소(`md` 48) / 전환(`md` 48, `primary`) |

### 3.2 태블릿 가로 (960px 이상)

세로 배치를 그대로 쓰고 가운데 정렬한다. 본문 최대 폭 1040px 안에서 마법사 열 폭은 SET-03 3.2와 같다.

### 3.3 휴대폰 (600px 미만)

```
┌──────────────────────────────┐
│ 문서 서비스 변경               │  상단 바 56px (제목만)
├──────────────────────────────┤
│ 3/4 자료 이전                  │
│ ┌──────────────────────────┐ │
│ │ Notion (현재, 원본 보존)    │ │
│ │          ↓               │ │
│ │ Confluence Cloud (새 연결) │ │
│ └──────────────────────────┘ │
│ ◉ 전체 복사 (권장)             │  라디오 행 48 이상
│   참석자 n명, 회의록 n건 복사    │
│ ○ 빈 구조로 새 시작             │
│ [⚠ 복사 제외: 첨부, 댓글, …  ] │
│ [         취소             ] │  보조 버튼 md 48
├──────────────────────────────┤
│ [     문서 서비스 전환       ] │  주 버튼 lg 56, 하단 고정
└──────────────────────────────┘
```

- 1단, 좌우 여백 16px. 하단 탭 바 없음(집중 모드). 단계 표시는 "3/4 자료 이전" 형태.
- 현재 → 새 서비스는 폭이 좁아 위아래(↓)로 배치한다.
- "문서 서비스 전환"은 주 버튼 `lg` 56, 폭 가득으로 하단에 고정하고 하단 안전 영역만큼 띄운다. 취소는 본문 끝에 폭 가득 보조 버튼 `md` 48.
- `short`(높이 560px 이하)에서는 고정 버튼을 본문 끝으로 옮긴다.
- 최종 확인(제안)은 하단 시트로 연다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 선택 대기 | 라디오 + 전환 버튼 |
| 시작 중 | 버튼 로딩 |
| 시작 실패·불명확 | 오류 문구 + 상태 확인 카드 |
| 전환 진행 | SET-05 (SWITCH) |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 되돌리기 어려운 작업인데 텍스트 단락 위주라 영향 범위가 한눈에 들어오지 않는다.
- **제안** — 최종 확인 모달("Notion → Confluence로 전환합니다. 전환 후 새 회의록은 Confluence에 저장됩니다.") 추가, 진행 중 복사 건수 진행 막대.
- **확인 필요** — D-05(관리자 전용). 화면 크기 기준은 D-06(태블릿 기준)으로 결정됨. 전환 중 다른 사용자의 회의 생성·검토가 막히는지(Backend 잠금 동작)와 그 안내 방법.
