# CMN-02 서버 연결 복구

| 항목 | 내용 |
|---|---|
| 화면 ID | CMN-02 |
| 유형 | 전체 화면 오버레이 (모달) |
| 경로 | 전체 |
| 현재 구현 | `frontend/src/components/BackendRecoveryOverlay.tsx`, `apiRecovery.ts` |
| 진입 조건 | API 요청이 Backend 연결 실패로 끝났을 때 자동 표시 |
| 사용 API | API-034 시스템 상태 확인 (복구 확인) |
| 현행 캡처 | 없음 |

## 1. 화면 개요

Backend(GCE)가 응답하지 않을 때 사용자에게 알리고, 연결이 돌아올 때까지 확인을 이어가는 오버레이다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| CMN-02-F01 | 자동 표시 | 연결 실패를 감지하면 표시 | 배경 스크롤 잠금, 닫기 버튼에 초점 |
| CMN-02-F02 | 자동 재확인 | 연결이 돌아올 때까지 확인 반복 | 복구되면 "서버가 다시 열렸어요"로 바뀐 뒤 자동으로 닫힘 |
| CMN-02-F03 | 수동 재확인 | 다시 확인 버튼 | 즉시 재확인 |
| CMN-02-F04 | 닫기 | 화면으로 돌아가기, ×, Esc | 오버레이만 닫고 진행 중인 화면은 유지 |

## 3. 화면 구성 요소

화면 기준은 마이크가 있는 태블릿이다. PC 전용 배치는 만들지 않는다(D-06). 크기·글자·컴포넌트 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 8장을 따른다. 오버레이는 내비게이션 레일·하단 탭 바·상단 바를 모두 덮는다.

### 3.1 태블릿 (기준, 폭 600px 이상)

```
┌──────────────────────────────────────────────────────┐
│                                                [×]   │  아이콘 버튼 48
│                                                      │
│                    ┌──────────────┐                  │
│                    │  상태 일러스트  │                  │
│                    └──────────────┘                  │
│                                                      │
│                  DOWNFORCE MINUTES                   │  caption
│              서버 연결을 확인하고 있어요                  │  headline
│      연결이 다시 준비될 때까지 확인을 이어가고 있어요.          │  body
│                                                      │
│           [ 화면으로 돌아가기 ]  [   다시 확인   ]          │  lg 56
│                                                      │
└──────────────────────────────────────────────────────┘
 전체 화면 덮개, 내용은 가운데 정렬
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 배경 | 오버레이 | 전체 화면 | 배경 `bg`(흰색)로 화면 전체를 덮는다(제안). 내용은 세로·가로 가운데 정렬, 내용 최대 폭은 대화상자와 같은 560px(제안) |
| 상단 | 닫기 | 아이콘 버튼 | "복구 대기 닫기". 48×48, 아이콘 24. 오른쪽 위, 위쪽 안전 영역만큼 띄움 |
| 시각 요소 | 상태 일러스트 | SVG 애니메이션 | 대기 중 / 복구됨 두 가지 상태. 동작 줄이기 설정 시 애니메이션 최소화. 색은 CI 3색(분홍·파랑·보라)을 쓴다. 크기는 **확인 필요** (제안: 태블릿 160px / 휴대폰 120px, 8장에 일러스트 크기 기준 없음) |
| 문구 | 보조 제목 | 텍스트 | DOWNFORCE MINUTES (현행: WINDSOFT MINUTES, D-10). `caption`, `brand-text`(분홍 글자) |
| | 제목 | 제목 | 대기: "서버 연결을 확인하고 있어요" / 복구: "서버가 다시 열렸어요". `headline`(태블릿 28/36) |
| | 설명 | 텍스트 | 대기: "연결이 다시 준비될 때까지 확인을 이어가고 있어요." / 복구: "잠시 후 진행 중인 화면으로 돌아갑니다." `body`, `text-muted` |
| 버튼 | 다시 확인 | 주 버튼 | 대기 상태에서만 표시. 버튼 `lg`(높이 56), `primary` 색 |
| | 화면으로 돌아가기 | 보조 버튼 | 대기 상태에서만 표시. 버튼 `lg`(높이 56), `primary-soft`. 태블릿은 두 버튼을 가로로 나란히(사이 8 이상), 주 버튼을 오른쪽에 둔다 |

### 3.2 태블릿 가로 (폭 960px 이상)

세로 배치를 그대로 쓰고 내용을 화면 가운데에 둔다.

### 3.3 휴대폰 (폭 600px 미만)

- 화면 전체를 덮는다. 좌우 여백 16px, 제목은 `headline` 휴대폰 크기(24/32).
- 두 버튼은 화면 아래쪽에 화면 폭 가득 세로로 쌓는다(위: 다시 확인, 아래: 화면으로 돌아가기, 사이 8). 아래쪽 안전 영역만큼 띄운다.
- 높이가 낮은 화면(`short`, 높이 560px 이하)에서는 일러스트를 줄이거나 숨기고 버튼을 본문 끝으로 옮긴다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 확인 중 | 대기 일러스트, 버튼 2개 |
| 복구됨 | 복구 일러스트, 버튼 없음, 자동 닫힘 |

## 5. 리뉴얼 검토 사항

- **제안** — 녹음 중(MTG-02)에는 오버레이가 녹음 화면을 가리지 않도록 상단 배너 형태로 낮춰 표시하는 방안 검토. 녹음 데이터는 브라우저에 먼저 저장되므로 녹음 자체는 계속된다는 안내 추가.
- **제안 (녹음 중 배너 크기)** — 위 상단 배너는 녹음 화면의 상단 바(휴대폰 56 / 태블릿 64) 아래에 붙여 녹음 주 버튼·시간 표시를 가리지 않게 한다. 배너 색은 `warning-soft` + 아이콘. 배너 높이는 **확인 필요** (제안: 목록 행 1줄과 같은 휴대폰 56 / 태블릿 60).
- **확인 필요** — 로그인 도입 후 401(인증 만료)과 연결 실패를 구분해 다르게 안내해야 한다(D-01). 오버레이 내용 최대 폭(제안 560px)과 일러스트 크기는 8장에 기준이 없다.
