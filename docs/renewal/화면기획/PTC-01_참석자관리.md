# PTC-01 참석자 관리

| 항목 | 내용 |
|---|---|
| 화면 ID | PTC-01 |
| 유형 | 페이지 (목록 + 팝업 편집) |
| 경로 | `/participants` (`/settings/participants`도 같은 화면) |
| 현재 구현 | `frontend/src/App.tsx` `ParticipantsPage`, `participantsApi.ts` |
| 진입 조건 | 로그인(신규) + CMN-04 통과 |
| 연결 화면 | MTG-01·MTG-04의 "참석자 관리" 링크로 진입 |
| 하위 팝업 | PTC-01-P01 참석자 추가·수정, PTC-01-P02 참석자 삭제 확인 |
| 사용 API | API-003 목록, API-004 추가, API-005 수정, API-031 삭제 |
| 현행 캡처 | [참석자 화면](<../현_UI/참석자 화면.png>), [참석자 추가 화면](<../현_UI/참석자 추가 화면.png>) |

## 1. 화면 개요

회의에 선택할 참석자(이름, 이메일)를 관리한다. 참석자 정보는 연결된 문서 서비스(Participants 페이지)에 저장되며, 회의록 이메일 수신자로 쓰인다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| PTC-01-F01 | 참석자 목록 | 이름, 이메일 | 이름 첫 글자 아바타 |
| PTC-01-F02 | 검색 | 이름 또는 이메일 | 입력 즉시 화면 내 필터, 지우기 버튼 |
| PTC-01-F03 | 참석자 추가 | PTC-01-P01 | 이름·이메일 필수, 이메일 형식 검사. 같은 입력 재시도는 같은 멱등 키 |
| PTC-01-F04 | 참석자 수정 | PTC-01-P01 | 바뀐 값만 전송. 변경 없으면 그냥 닫음 |
| PTC-01-F05 | 참석자 삭제 | PTC-01-P02 확인 후 | 문서 서비스에서 삭제 |
| PTC-01-F06 | 결과 알림 | Toast | 참석자를 추가했습니다 / 수정했습니다 / 삭제했습니다 |
| PTC-01-F07 | 충돌 처리 | 문서 변경 중·버전 충돌·이미 삭제됨 | 서버 문구 표시, 필요 시 "목록 새로고침" |
| PTC-01-F08 | 일괄 등록 | CSV 등으로 여러 명 등록 | **제안** (선택, Backend 일괄 API 없음 → 1건씩 호출) |

## 3. 화면 구성 요소

### 3.1 데스크톱 (제안)

```
┌ 상단 바: 참석자                                      [+ 참석자 추가] ┐
│ [🔍 이름 또는 이메일 검색          ]                    참석자 12명   │
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │ (홍) 홍길동     hong@company.com                   [수정] [삭제] │ │
│ │ (김) 김철수     kim@company.com                    [수정] [삭제] │ │
│ └──────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 | 제목 | 제목 | 참석자 |
| | 참석자 추가 | 주 버튼 | 현행: 화면 하단 고정 → 상단 바 우측(제안) |
| 검색 | 검색 입력 | 검색 상자 | placeholder "이름 또는 이메일 검색", 지우기 |
| | 인원 수 | 텍스트 | 참석자 목록 n명 |
| 목록 | 참석자 행 | 표(데스크톱) / 카드(모바일) | 아바타, 이름, 이메일, 수정, 삭제 |

### 3.2 PTC-01-P01 참석자 추가·수정

| 요소 | 유형 | 내용·규칙 |
|---|---|---|
| 보조 제목 / 제목 | 텍스트 | 참석자 관리 / 참석자 추가 또는 참석자 수정 |
| 설명 | 텍스트 | 이름과 이메일 정보를 입력해 주세요. |
| 이름 | 텍스트 입력 | 필수, 열릴 때 자동 초점, `autocomplete=name` |
| 이메일 | 이메일 입력 | 필수, 형식 검사 |
| 오류 | 텍스트 | 입력란별 오류 + 폼 오류 |
| 목록 새로고침 | 보조 버튼 | 대상이 사라진 경우 |
| 저장 | 주 버튼 | 저장 중 "저장 중…" |
| 닫기 | 아이콘 버튼 | ×, Esc. 저장 중에는 닫기 불가. 닫으면 연 버튼으로 초점 복귀 |
| 형태 (제안) | 모달 | 데스크톱은 폭 480px 가운데 모달, 모바일은 하단 시트. 현행은 데스크톱에서도 전체 화면 |

### 3.3 PTC-01-P02 참석자 삭제 확인

| 요소 | 내용 |
|---|---|
| 제목 | 삭제하시겠습니까? |
| 본문 | **{이름}** 참석자 정보를 연결된 문서 서비스에서 삭제합니다. |
| 버튼 | 아니요 / 예(위험) — 제안: "취소 / 삭제"로 명확화 |
| 오류 | 이미 삭제된 참석자입니다. 목록을 새로고침해 주세요. 등 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 로딩 | "참석자 목록을 불러오는 중…" |
| 없음 | "등록된 참석자가 없습니다. / 참석자를 추가하면 회의에서 선택할 수 있습니다." + 추가 버튼 (제안: 빈 상태 안에 버튼) |
| 검색 결과 없음 | "검색 결과가 없습니다 / 다른 이름이나 이메일로 검색해 보세요." + 검색어 지우기 |
| 조회 실패 | 오류 카드 + 다시 시도 |

## 5. 메시지 (현행)

| 구분 | 문구 |
|---|---|
| 이름 누락 | 이름을 입력해 주세요. |
| 이메일 누락 | 이메일을 입력해 주세요. |
| 이메일 형식 | 올바른 이메일 주소를 입력해 주세요. |
| 저장 실패 | 저장하지 못했습니다. 입력값을 확인한 뒤 다시 시도해 주세요. |
| 대상 없음 | 이 참석자는 목록에서 사라졌습니다. 목록을 새로고침한 뒤 다시 시도해 주세요. |

## 6. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 추가 폼이 데스크톱에서 전체 화면으로 열려 빈 공간이 크고 헤더·메뉴가 사라진다(캡처). 삭제 확인 버튼이 "아니요/예"로 결과가 명확하지 않다.
- **제안** — 표 형식 목록, 모달 폼, 이메일 중복 사전 안내, 회의 참석 횟수 등 부가 정보(선택).
- **확인 필요** — D-02: 로그인 허용 대상을 참석자 목록으로 정하면 이 화면이 사용자 관리 역할도 하게 된다. 이 경우 권한(D-05)과 문구를 함께 조정해야 한다.
