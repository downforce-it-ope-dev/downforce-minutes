# MTG-03 회의 처리

| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-03 |
| 유형 | 페이지 (집중 모드 — 메뉴 숨김) |
| 경로 | `/meetings/:sessionId/processing` |
| 현재 구현 | `frontend/src/ProcessingPage.tsx`, `processingPoller.ts` |
| 진입 조건 | MTG-02 종료 후 자동 이동, MIN-01 처리 실패 회의 재처리 |
| 연결 화면 | 처리 완료(`REVIEW`) → MTG-04 자동 이동 / 세션 없음 → MTG-01 |

| 현행 캡처 | 없음 |

## 1. 화면 개요

녹음한 오디오로 음성 인식, 화자 분석, 회의록 초안 생성을 진행하는 동안 단계별 진행 상황을 보여 준다. 실패하면 재시도, 원본 오디오 다운로드, 오디오 없이 마무리를 고를 수 있다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MTG-03-F01 | 단계 표시 | 오디오 준비 → 음성 인식 → 화자 분석 → 회의록 생성 | 완료·진행 중·대기 표시. "전체 4단계 중 n단계 · {단계} 진행 중" |
| MTG-03-F02 | 진행률 | 단계 기반 진행 막대 | 서버 진행률은 작업 단계 기준이며 오디오 처리량이 아님 |
| MTG-03-F03 | 음성 인식 경과 시간 | 음성 인식 단계에서만 | mm:ss |
| MTG-03-F04 | 상태 자동 갱신 | 주기적 조회 | 화면 복귀(포커스·표시 전환) 시 즉시 재조회 |
| MTG-03-F05 | 검토 화면 이동 | `REVIEW`가 되면 | MTG-04로 교체 이동 |
| MTG-03-F06 | 처리 재시도 | 실패 시 | 서버가 허용(`RETRY_PROCESSING`)할 때만 |
| MTG-03-F07 | 원본 오디오 다운로드 | 실패 시 | "다운로드 준비"로 최신 상태 확인 → 다운로드 링크 표시 → 다운로드 후 MTG-03-P01 |
| MTG-03-F08 | 오디오 없이 마무리 | 실패 시 | MTG-03-P02 확인 후 실패 기록 저장(`DISCARDED`) |
| MTG-03-F09 | 오디오 보관 만료 표시 | 실패 시 | 남은 분 표시, 만료 시 자동 재조회 |
| MTG-03-F10 | 이탈 방지 | 처리 중 이동 경고 | CMN-01-P01 |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4절·8장을 따른다. 이 화면은 집중 모드다(CMN-01). 태블릿의 내비게이션 레일과 휴대폰의 하단 탭 바를 숨기고, 상단 바에는 제목만 둔다. 녹음을 마친 태블릿을 탁자에 둔 채 진행 상황을 보는 장면을 기준으로 한다.

### 3.1 태블릿 (기준, 600px 이상)

태블릿 세로(폭 820px 전후) 기준. 레일 없이 본문을 가운데 1단으로 둔다. 좌우 여백 24px.

```
┌ 상단 바 64px: 회의 처리 ───────────────────────────────────────────┐
│                                                                 │
│  주간 회의 (제안: 회의 제목 표시)                            title    │
│  녹음 길이 01:02:15 (제안)                                caption   │
│                                                                 │
│   (✓)───────────(●)───────────(○)───────────(○)                 │
│  오디오 준비     음성 인식       화자 분석       회의록 생성     label    │
│                                                                 │
│  전체 4단계 중 2단계 · 음성 인식 진행 중              경과 03:12       │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━░░░░░░░░░░░░░░░░░░░░░░░░             │
│                                                                 │
│  화면을 닫아도 처리는 계속됩니다. (제안 — 확인 필요)         caption     │
│                                                                 │
└───────────────────────────────────────────────────────────────────┘

처리 실패 시 (본문 아래에 실패 카드)
┌ 실패 카드 (안쪽 여백 24, danger-soft 머리) ───────────────────────────┐
│  ⚠ 처리를 완료하지 못했습니다                                 title    │
│  실패한 단계 · 음성 인식                                              │
│  {오류 코드별 문구}                                          body     │
│  오디오 보관: 약 42분 남았습니다                                caption   │
│                                                                 │
│  [            다시 시도            ] 56                             │
│  [ 오디오 다운로드 준비 ] 48    [ 오디오 없이 실패 마무리 ] 48              │
└───────────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 바 (높이 64) | 제목 | 제목 | 회의 처리. `headline` 28/36. 뒤로 가기 없음(집중 모드) |
| 회의 정보 | 회의 제목 | 텍스트 | **제안**. `title` 20/28 |
| | 녹음 길이 | 텍스트 | **제안**. `caption` 14/20, `tabular-nums`, `text-muted` |
| 진행 | 단계 표시 | 단계 표시기(Stepper) | 4단계. 태블릿은 가로. 완료 = 체크 아이콘 + `primary` 색, 진행 중 = `primary` 테두리 + 점, 대기 = `border-input` 테두리. 색만으로 구분하지 않도록 아이콘과 단계 이름(`label` 16/24)을 함께 표시. 단계 원 크기는 8.5에 정의 없음 → **확인 필요**(제안: 지름 32, 누르는 대상 아님) |
| | 현재 단계 문구 | 상태 텍스트 | `body` 16/24. 스크린리더 실시간 알림 |
| | 진행 막대 | 진행 막대 | 단계 기준. `primary`. 막대 높이는 8.5에 정의 없음 → **확인 필요**(제안: 8) |
| | 경과 시간 | 타이머 | 음성 인식 중에만. mm:ss, `title` 20/28 + `tabular-nums`. 녹음 화면처럼 `display`를 쓰지 않는다(주 정보는 단계) |
| | 계속 진행 안내 | 텍스트 | **제안 — 확인 필요**(5장). `caption`, `text-muted` |
| 실패 (카드) | 제목 | 제목 | 처리를 완료하지 못했습니다. `title` + 경고 아이콘. 카드 머리는 `danger-soft`(red-50 배경 + red-700 글자) |
| | 원인 | 텍스트 | 오류 코드별 문구. `body` |
| | 실패 단계 | 텍스트 | 실패한 단계 · {단계} |
| | 오디오 보관 만료 | 텍스트 | 약 n분 남았습니다 / 만료 시각이 지났습니다. `caption`, `tabular-nums` |
| | 다시 시도 | 주 버튼 `lg` | 높이 56, `primary`. 허용 시 |
| | 오디오 다운로드 준비 → 원본 오디오 다운로드 | 보조 버튼 `md` → 링크 | 높이 48, `primary-soft`. 허용 + 오디오 있음. 링크도 누르는 영역 48 이상 |
| | 오디오 없이 실패 마무리 | 보조 버튼 `md` | 높이 48. 허용 시. 되돌릴 수 없는 동작이므로 다시 시도와 8px 이상 띄운다 |
| | 작업 오류 문구 | 경고 텍스트 | 요청 실패 시. `danger-soft` |

### 3.2 태블릿 가로 (960px 이상)

세로 배치를 그대로 쓰고 본문 최대 폭 1040px로 가운데 정렬한다. 좌우 여백 32px.

### 3.3 휴대폰 (600px 미만)

1단. 상단 바 56px, 좌우 여백 16px. 단계 표시는 세로로 쌓는다(기존 안 유지).

```
┌ 상단 바 56px: 회의 처리 ──────────┐
│ 주간 회의                  title │
│                                │
│ (✓) 오디오 준비                   │
│  │                             │
│ (●) 음성 인식 · 경과 03:12        │
│  │                             │
│ (○) 화자 분석                     │
│  │                             │
│ (○) 회의록 생성                   │
│                                │
│ 전체 4단계 중 2단계               │
│ ━━━━━━━━━━━░░░░░░░░░░░          │
│ 화면을 닫아도 처리는 계속됩니다.     │
│ (제안 — 확인 필요)                │
└──────────── 하단 안전 영역 ───────┘

처리 실패 시
│ ⚠ 처리를 완료하지 못했습니다         │
│ {원인} · 보관 약 42분 남음          │
│ [ 오디오 다운로드 준비       ] 48   │
│ [ 오디오 없이 실패 마무리     ] 48   │
├────────────────────────────────┤
│ [        다시 시도          ] 56  │  하단 고정, 폭 가득
└──────────── 하단 안전 영역 ───────┘
```

- 세로 단계 행 높이는 48로 둔다(제안. 누르는 대상은 아니며 단계 이름 `label` 15/22 한 줄 기준). 진행 중 단계 옆에 경과 시간을 함께 둔다.
- 처리 실패 시 주 버튼(다시 시도)을 하단 안전 영역 위에 폭 가득 고정한다. 보조 버튼 2개는 본문 안에 세로로 쌓아 폭 가득 둔다. 다시 시도가 허용되지 않으면 고정 버튼 영역을 표시하지 않는다.
- MTG-03-P01·P02는 하단 시트로 띄운다(3.5·3.6).
- **높이가 낮은 화면(`short`, 높이 560px 이하 — 휴대폰 가로):** 상단 바와 여백을 줄이고 고정된 다시 시도 버튼을 본문 끝으로 옮긴다. 휴대폰 가로는 동작만 보장한다.
- 이 화면에는 입력란이 없으므로 화면 키보드 대응은 필요 없다.

### 3.4 처리 중 기기 상태 (태블릿·휴대폰 공통)

| 상황 | 규칙 | 상태 |
|---|---|---|
| 화면 꺼짐 (자동 잠금) | 처리 중에는 화면 꺼짐 방지를 요청하지 않는다(제안). 화면이 다시 켜지면 즉시 재조회한다 | 현행: 화면 복귀(`visibilitychange`·`focus`) 시 즉시 재조회(MTG-03-F04). 화면이 꺼진 동안 서버 처리가 계속되는지는 5장 확인 필요 항목과 같다 |
| 화면 방향 전환 | 배치만 바뀌고 조회는 끊기지 않는다 | **확인 필요**: 실제 기기 검증 기록 없음 |
| 원본 오디오 다운로드 | 태블릿·휴대폰에서 다운로드한 파일이 기기에 저장되는지 확인한 뒤 MTG-03-P01로 기록한다(현행) | **확인 필요**: iPad·iPhone Safari와 Android Chrome에서 다운로드 저장 위치·동작이 다르다. 사용자가 저장 여부를 판단할 수 있는 안내 문구 필요 여부 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 회의 제목이 표시되지 않아 어떤 회의를 처리 중인지 알 수 없다. 실패 복구 확인이 화면 안 영역으로 나타나 팝업과 구분이 약하다.
- **제안** — 회의 제목·녹음 길이 표시, 실패 복구 확인을 대화상자(휴대폰은 하단 시트)로 통일, 단계별 예상 소요 안내, 태블릿 가로 단계 표시·휴대폰 세로 단계 표시.
- **결정** — D-06: 마이크가 있는 태블릿 기준, 휴대폰까지 지원, PC는 고려하지 않음(2026-11-06).
- **확인 필요** — 처리 중에 화면을 떠나도 서버 처리가 계속되는지(Backend 비동기 처리 여부)를 확인해 이탈 경고 문구와 "닫아도 됩니다" 안내 중 무엇을 쓸지 정한다. 단계 표시 원·진행 막대 크기(8.5에 정의 없음). 태블릿·휴대폰에서 원본 오디오 다운로드 저장 동작(3.4).
