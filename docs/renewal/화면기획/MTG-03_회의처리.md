# MTG-03 회의 처리

| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-03 |
| 유형 | 페이지 (집중 모드 — 메뉴 숨김) |
| 경로 | `/meetings/:sessionId/processing` |
| 현재 구현 | `frontend/src/ProcessingPage.tsx`, `processingPoller.ts` |
| 진입 조건 | MTG-02 종료 후 자동 이동, MIN-01 처리 실패 회의 재처리 |
| 연결 화면 | 처리 완료(`REVIEW`) → MTG-04 자동 이동 / 세션 없음 → MTG-01 |
| 하위 팝업 | MTG-03-P01 오디오 저장 확인, MTG-03-P02 오디오 없이 마무리 확인 |
| 사용 API | API-010 상태 조회(반복), API-020 처리 재시도, API-021 원본 오디오 다운로드, API-022 실패 마무리 |
| 현행 캡처 | 없음 |

## 1. 화면 개요

녹음한 오디오로 음성 인식, 화자 분석, 회의록 초안 생성을 진행하는 동안 단계별 진행 상황을 보여 준다. 실패하면 재시도, 원본 오디오 다운로드, 오디오 없이 마무리를 고를 수 있다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| MTG-03-F01 | 단계 표시 | 오디오 준비 → 음성 인식 → 화자 분석 → 회의록 생성 | 완료·진행 중·대기 표시. "전체 4단계 중 n단계 · {단계} 진행 중" |
| MTG-03-F02 | 진행률 | 단계 기반 진행 막대 | 서버 진행률은 작업 단계 기준이며 오디오 처리량이 아님 |
| MTG-03-F03 | 음성 인식 경과 시간 | 음성 인식 단계에서만 | mm:ss |
| MTG-03-F04 | 상태 자동 갱신 | 주기적 조회 | 화면 복귀(포커스·표시 전환) 시 즉시 재조회 |
| MTG-03-F05 | 검토 화면 이동 | `REVIEW`가 되면 | MTG-04로 교체 이동 |
| MTG-03-F06 | 처리 재시도 | 실패 시 | 서버가 허용(`RETRY_PROCESSING`)할 때만 |
| MTG-03-F07 | 원본 오디오 다운로드 | 실패 시 | "다운로드 준비"로 최신 상태 확인 → 다운로드 링크 표시 → 다운로드 후 MTG-03-P01 |
| MTG-03-F08 | 오디오 없이 마무리 | 실패 시 | MTG-03-P02 확인 후 실패 기록 저장(`DISCARDED`) |
| MTG-03-F09 | 오디오 보관 만료 표시 | 실패 시 | 남은 분 표시, 만료 시 자동 재조회 |
| MTG-03-F10 | 이탈 방지 | 처리 중 이동 경고 | CMN-01-P01 |

### 실패 원인 문구 (현행, 오류 코드별)

| 오류 코드 | 문구 |
|---|---|
| AUDIO_ASSEMBLY_FAILED | 녹음 파일 조각을 하나의 오디오로 준비하지 못했습니다. 다시 시도해 주세요. |
| AUDIO_STORAGE_FAILED | 오디오 파일을 안전하게 보관하지 못했습니다. 다시 시도해도 해결되지 않으면 새 회의를 녹음해 주세요. |
| TRANSCRIPTION_* | 음성 인식 서비스 연결·설정·처리 관련 안내 (6종) |
| DIARIZATION_* | 화자 분석 실패·저장 실패 안내 (2종) |
| MINUTES_* | 회의록 작성 서비스 연결·설정·처리·저장 안내 (4종) |
| PROCESSING_RUNNER_FAILED / PROCESSING_FAILED | 회의 처리 작업 중단 / 일시적 문제 안내 |

전체 문구는 `ProcessingPage.tsx`의 `failureDetails`를 따른다.

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 첫 조회 중 | "회의 처리 상태를 확인하고 있습니다." |
| 처리 중 | 단계 표시 + 진행 막대 |
| 처리 실패 | 실패 카드 + 복구 버튼 |
| 실패 기록 저장됨 (`COMPLETED_WITH_WARNINGS`) | "실패 기록을 저장했습니다 / Email 또는 Slack으로 회의가 전달되지 않았습니다." |
| 네트워크 오류 | 첫 조회 전: 오류 카드 + 다시 시도. 조회 후: 기존 화면 유지 + 경고. 자동 재확인 |
| 세션 없음 | "회의를 찾을 수 없습니다" + 새 회의 시작 |
| 응답 이상·조회 불가 | "회의 처리 상태를 확인할 수 없습니다. 잠시 후 다시 시도해 주세요." |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 회의 제목이 표시되지 않아 어떤 회의를 처리 중인지 알 수 없다. 실패 복구 확인이 화면 안 영역으로 나타나 팝업과 구분이 약하다.
- **제안** — 회의 제목·녹음 길이 표시, 실패 복구 확인을 모달로 통일, 단계별 예상 소요 안내.
- **확인 필요** — 처리 중에 화면을 떠나도 서버 처리가 계속되는지(Backend 비동기 처리 여부)를 확인해 이탈 경고 문구와 "닫아도 됩니다" 안내 중 무엇을 쓸지 정한다.
