## 1. 화면 개요

마이크를 확인하고 회의를 녹음한다. 녹음 데이터는 조각 단위로 브라우저(IndexedDB)에 먼저 저장한 뒤 서버로 올린다. 종료하면 업로드를 마무리하고 회의록 처리를 시작한다.

## 3. 화면 구성 요소

녹음은 이 서비스의 핵심 사용 장면이다. 기준 장면은 **마이크가 있는 태블릿을 회의 탁자에 세워 두거나 눕혀 두고 녹음하는 것**이다. 참석자가 1~2m 떨어진 곳에서도 녹음 여부와 경과 시간을 알아볼 수 있어야 하고, 녹음 중 실수로 다른 버튼을 누르지 않아야 한다. 크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4절·8장을 따른다.

이 화면은 집중 모드다(CMN-01). 태블릿의 내비게이션 레일과 휴대폰의 하단 탭 바를 모두 숨기고, 상단 바에는 제목과 (녹음 시작 전에만) 뒤로 가기만 둔다.

### 3.1 태블릿 (기준, 600px 이상)

태블릿 세로(폭 820px 전후) 기준. 녹음 패널을 화면 가운데 1단으로 둔다.

```
┌ 상단 바 64px: ← 회의 녹음 (시작 전에만 뒤로 가기) ───────────────────┐
│                                                                  │
│                         주간 회의                    title        │
│                                                                  │
│                    ┌──────────────┐                              │
│                    │ ● 녹음 중      │  상태 배지 (분홍 brand + 검은 글자) │
│                    └──────────────┘                              │
│                                                                  │
│                       00:12:34                display 64/72       │
│                                                                  │
│      ┌ 마이크 56px ──────────────────────────────────────────┐    │
│      │ 🎙  ▁▃▅▇▅▃▁▃▅▇▅▃▁▃▅▇▅▃▁   마이크 입력이 감지되었습니다  (↻) │    │
│      └────────────────────────────────────────────────────┘    │
│                                                                  │
│               ✓ 자동 저장됨 · 12조각 (제안)          caption       │
│                                                                  │
│                                                                  │
│                      ┌──────┐          ┌────┐                    │
│                      │  ❙❙  │   ≥24px  │ ■  │                    │
│                      │  96  │          │ 64 │                    │
│                      └──────┘          └────┘                    │
│                      일시정지           회의 종료                    │
│                                                                  │
└──────────────────────────────── 하단 안전 영역 ─────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 바 (높이 64) | 뒤로 가기 | 아이콘 버튼 48×48 | 녹음 시작 전에만 표시 ("회의 준비로 돌아가기") |
| | 제목 | 제목 | 회의 녹음. `headline` 28/36 |
| 회의 정보 | 회의 제목 | 텍스트 | 세션의 회의 제목. `title` 20/28, 2줄 넘으면 말줄임 (제안) |
| | 녹음 상태 | 상태 배지 | 녹음 중 / 일시정지됨 / 녹음이 종료되었습니다. 현행: 녹음 중은 빨간 점 깜빡임. **제안**: 녹음 중은 `brand`(분홍 CI pink-300 배경 + neutral-900 글자), 일시정지는 `accent`(보라 CI) 또는 중립 배경 + neutral-900 글자. 흰 글자는 쓰지 않는다(7.4 사용 규칙). 빨강은 오류와 혼동되므로 녹음 중 표시에 쓰지 않는다. 상태는 점 아이콘 + 문구로 함께 표시. 배지 글자는 태블릿 `title` 20/28, 휴대폰 `label` 15/22. 탁자에 둔 태블릿을 떨어져서 봐도 상태를 읽을 수 있게 한다 |
| | 경과 시간 | 대형 숫자 | HH:MM:SS. `display` 64/72, 굵기 600, `tabular-nums`, 자간 -0.02em. 색은 `text`(neutral-900) |
| 마이크 (높이 56) | 상태 아이콘 + 표시등 | 시각 요소 | 상태별 색 + 문구 함께 표시 (확인 중·대기·감지·오류). 오류는 `danger-soft`, 감지는 `success-soft` (제안) |
| | 입력 파형 | 시각 요소 | 입력 레벨 반영(현행 21개 막대). 스크린리더용 "마이크 입력 레벨 n%" |
| | 상태 문구 | 텍스트 | `body` 16/24. 마이크를 확인하고 있습니다 / 사용할 수 없습니다 / 입력 대기 중 / 입력이 감지되었습니다 |
| | 다시 확인 | 아이콘 버튼 48×48 | 오류·입력 없음일 때 |
| 업로드 | 진행 표시 | 진행 막대 | 완료 조각/전체 조각. 녹음 중에는 실패·재시도 필요할 때만 표시. 막대 색은 `primary`(진행 표시) |
| | 자동 저장 표시 | 텍스트 | **제안**: "자동 저장됨 · n조각" `caption` 14/20, `text-muted` |
| | 업로드 재시도 | 보조 버튼 `md` 48 | 재시도 가능 상태일 때. `primary-soft` |
| 종료 처리 | 진행 단계 문구 + 진행 막대 | 상태 | 정지 중 → 저장 확인 → 업로드 → 처리 시작. 문구 `body` |
| | 처리 시작 재시도 | 보조 버튼 `md` 48 | 실패 시 |
| 행동 버튼 | 녹음 시작 | 녹음 주 버튼 (원형, 지름 96) | 시작 전. `primary`(파랑 blue-600) 배경 + 흰 아이콘. 버튼 아래 이름 `label` |
| | 일시정지 / 녹음 재개 | 녹음 주 버튼 (원형, 지름 96) | 녹음 중 / 일시정지 중. 현행은 일시정지가 보조 버튼이지만, 8.5 기준에 따라 시작·일시정지·재개를 같은 자리의 주 버튼으로 둔다(제안). 아이콘만으로 상태를 구분하지 않도록 버튼 아래 이름 표시 |
| | 회의 종료 | 녹음 보조 버튼 (원형, 지름 64) | 녹음 중·일시정지 중. `danger`(red-600 + 흰 아이콘). 주 버튼과 24px 이상 띄운다. 현행 라벨 "완료" |
| | 새 회의 시작 / 회의록 목록 | 버튼 `lg` 56 / `md` 48 | 종료 처리 복구 상태에서 |
| 오류 | 오류 문구 | 경고 텍스트 | `danger-soft` 안내. 브라우저 저장 실패, 돌아가기 실패 등 |

- **탁자 위 가독성:** 경과 시간과 녹음 상태는 화면 위쪽 1/2 안에 두어 태블릿을 세우거나 눕혀도 보이게 한다. 상태 배지 글자는 태블릿에서 `title` 크기로 키운다(위 표).
- **오조작 방지:** 녹음 버튼 2개만 화면 아래쪽에 두고 그 외 누르는 요소(다시 확인, 업로드 재시도)는 버튼과 16px 이상 떨어진 위쪽에 둔다. 종료는 항상 MTG-02-P01을 거친다(현행).
- **hover 없음:** 버튼 설명은 hover 툴팁이 아니라 버튼 아래 이름으로 항상 보인다.

왼쪽에 녹음 패널, 오른쪽에 회의 정보를 둔다(**제안**). 본문 최대 폭 1040px, 좌우 여백 32px.

│  │            ● 녹음 중                        │  │ 2026-11-05                  │ │

│  │            00:12:34       display 64/72   │  │                             │ │
│  │                                           │  │ 참석자 3명                   │ │
│  │  🎙 ▁▃▅▇▅▃▁▃▅▇▅▃▁  입력이 감지되었습니다 (↻) │  │  홍길동                      │ │
│  │                                           │  │  김철수                      │ │

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 녹음 패널 | 3.1의 회의 정보 제외 전체 | - | 3.1과 같은 크기 |

- **확인 필요:** 현행 녹음 세션 정보(`App.tsx` `RecordingSession`)는 제목과 입력값(`draft`: 날짜, `templateId`, `participantIds`)만 보관한다. 참석자 이름·템플릿 이름을 보여 주려면 목록을 다시 불러오거나(API-002, API-003) 세션 저장 내용에 이름을 함께 넣어야 한다. 새로고침 복원 때도 같은 문제가 있다.

### 3.3 휴대폰 (600px 미만)

1단. 상태와 시간은 위쪽, 녹음 버튼은 엄지가 닿는 아래쪽에 둔다.

```
┌ 상단 바 56px: ← 회의 녹음 ───────┐
│                               │
│          주간 회의       title   │
│          ● 녹음 중               │
│                               │
│          00:12:34              │
│          display 48/56         │
│                               │
│ ┌ 마이크 48px ──────────────┐  │
│ │🎙 ▁▃▅▇▅▃▁▃▅  입력 감지  (↻) │  │
│ └──────────────────────────┘  │
│   ✓ 자동 저장됨 · 12조각         │
│                               │
│                               │
│      ( ❙❙ 80 )  ≥24  ( ■ 56 )  │
│      일시정지       회의 종료      │
└──────────── 하단 안전 영역 ───────┘
```

- 좌우 여백 16px. 경과 시간 `display` 48/56, 상단 바 제목 `headline` 24/32, 회의 제목 `title` 18/26.
- 녹음 주 버튼 지름 80, 보조 버튼 지름 56, 사이 24px 이상. 하단 안전 영역(`env(safe-area-inset-bottom)`) 위 24px에 둔다.
- 마이크 입력 표시 높이 48. 파형 막대 수는 폭에 맞춰 줄일 수 있다(**확인 필요**: 현행 21개 고정 여부).
- MTG-02-P01은 하단 시트로 띄운다(3.5).
- **높이가 낮은 화면(`short`, 높이 560px 이하 — 휴대폰 가로):** 상단 바와 여백을 줄이고 경과 시간과 버튼을 한 줄에 둔다(시간 왼쪽, 버튼 오른쪽). 버튼 크기는 줄이지 않는다. 휴대폰 가로는 동작만 보장한다(8.2).
- 녹음 화면에는 입력란이 없으므로 화면 키보드 대응은 필요 없다.

### 3.4 녹음 중 기기 상태 (태블릿·휴대폰 공통)

| 상황 | 규칙 | 상태 |
|---|---|---|
| 화면 방향 전환 (세로 ↔ 가로) | 배치만 3.1 ↔ 3.2(휴대폰은 3.3 `short`)로 바뀌고 녹음·경과 시간·업로드는 끊기지 않아야 한다 | **확인 필요**: 방향 전환 시 녹음이 유지되는지 실제 기기 검증 기록 없음. 화면 전환으로 녹음 구성 요소가 다시 만들어지지 않는지 확인 |
| 화면 꺼짐 (자동 잠금) | 녹음 중·일시정지 중에는 화면 꺼짐 방지(Wake Lock)를 요청한다(제안) | **확인 필요**: 현행 `frontend/src`에 화면 꺼짐 방지 처리가 없다(코드 검색 기준). 대상 브라우저 지원 여부와, 화면이 꺼졌을 때 녹음이 멈추는지 기기별 검증 필요(8.7) |
| 다른 앱·탭으로 전환 | 돌아왔을 때 녹음 상태와 업로드 현황을 다시 표시 | **확인 필요**: 백그라운드 전환 시 브라우저가 마이크 입력을 멈추는지 기기별 검증 필요 |
| 하단 안전 영역 | 녹음 버튼은 홈 표시줄과 겹치지 않게 안전 영역만큼 띄운다 | 8.5 |

### 3.5 MTG-02-P01 회의 종료 확인

| 요소 | 내용 |
|---|---|
| 형태 | 휴대폰: 하단 시트(폭 가득, `radius-xl` 20, 안쪽 여백 24). 태블릿: 가운데 대화상자(최대 폭 560). `shadow-overlay` |
| 제목 | 회의를 종료할까요? (`title`) |
| 본문 | 녹음을 종료하고 회의록 작성을 시작합니다. (`body`) |
| 버튼 | 계속 녹음(기본 초점, `md` 48 보조) / 회의 종료(위험, `md` 48 `danger`). 휴대폰은 두 버튼을 세로로 쌓아 폭 가득 채우고 8px 이상 띄운다. 기본 동작인 계속 녹음을 아래(엄지 쪽)에, 회의 종료를 위에 둔다 (제안) |
| 규칙 | Esc = 계속 녹음, 포커스 순환(현행). 터치: 시트 바깥 누르기 = 계속 녹음 (제안). 대화상자가 떠 있어도 녹음은 계속된다(현행 동작 확인 필요) |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 마이크 확인 중 | 시작 버튼 비활성, 확인 중 문구 |
| 마이크 사용 불가 | 오류 색 표시 + 다시 확인. **제안**: 브라우저 권한 허용 방법 안내 |
| 입력 대기 | 시작 버튼 비활성, "마이크 입력 대기 중" |
| 녹음 준비 완료 | 시작 버튼 활성 |
| 녹음 중 | 현행: 빨간 상태 + 일시정지·종료. **제안**: 분홍(`brand`) 상태 배지 + 일시정지·종료 |
| 일시정지 | 재개·종료 |
| 종료 처리 중 | 단계 문구 + 진행 막대, 버튼 숨김 |
| 업로드 실패 | 업로드 재시도 |
| 처리 시작 실패 | 처리 시작 재시도 + 새 회의·목록 버튼 |
| 브라우저 저장 실패 | "녹음 데이터를 브라우저 임시 저장소에 보관하지 못했습니다. 저장 공간이나 브라우저 상태를 확인해 주세요." 녹음 중단 |
| 세션 없음 | 안내 + 새 회의 시작 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 종료 버튼 라벨이 "완료"라 회의 종료 의미가 약하다. 녹음 중 업로드 상태가 보이지 않아 데이터가 안전한지 알기 어렵다.
- **제안**
  - 태블릿 가로(960px 이상)에서는 왼쪽 녹음 패널 + 오른쪽 회의 정보(참석자, 템플릿)를 함께 표시(3.2)
  - 탁자에 둔 태블릿에서 떨어져 보이도록 경과 시간 `display` 64/72, 녹음 주 버튼 지름 96
  - 녹음 중 상태는 빨강 대신 브랜드 분홍(`brand`) + 검은 글자로 표시해 오류와 구분
  - 녹음 중 업로드 상태를 작은 표시(예: "자동 저장됨 · 12조각")로 상시 노출
  - 화면 꺼짐 방지(Wake Lock) 지원 브라우저에서 적용 검토
  - 장시간 녹음 시 경과 시간 외에 예상 처리 시간 안내 여부 검토
- **결정** — D-06: 마이크가 있는 태블릿 기준, 휴대폰까지 지원, PC는 고려하지 않음(2026-11-06).
- **확인 필요**
  - 화면 방향 전환·화면 꺼짐·백그라운드 전환 시 녹음 유지 여부(3.4). 실제 태블릿·휴대폰에서 검증한다.
  - 녹음 상태 배지 글자 크기(`label` 16 vs `title` 20).
  - 태블릿 가로 회의 정보 표시에 필요한 참석자·템플릿 이름 확보 방법(3.2).
