| 항목 | 내용 |
|---|---|
| 화면 ID | MTG-02 |
| 유형 | 페이지 (집중 모드 — 메뉴 숨김) |
| 경로 | `/meetings/:sessionId/recording` |
| 현재 구현 | `frontend/src/RecordingPage.tsx`, `App.tsx` `MeetingRecordingRoute`, `recordingController.ts`, `chunkUploadCoordinator.ts`, `recordingEndCoordinator.ts` |
| 진입 조건 | MTG-01에서 세션 생성. 세션 정보는 브라우저 세션 저장소에 보관해 새로고침 시 복원 |

## 1. 화면 개요

마이크를 확인하고 회의를 녹음한다. 녹음 데이터는 조각 단위로 브라우저(IndexedDB)에 먼저 저장한 뒤 서버로 올린다. 종료하면 업로드를 마무리하고 회의록 처리를 시작한다.

## 3. 화면 구성 요소

```
┌ 상단 바: ← 회의 녹음 (시작 전에만 뒤로 가기) ─────────────────┐
│                                                         │
│                 주간 회의                                 │
│             ● 녹음 중                                     │
│              00:12:34                                    │
│                                                         │
│        [🎙]  ▁▃▅▇▅▃▁▃▅▇▅▃▁▃▅▇▅▃▁   (↻)                    │
│        마이크 입력이 감지되었습니다                            │
│                                                         │
│   ┌ 오디오 업로드  12/14 ━━━━━━━━━━━━━━━━━━━━━━░░ ┐          │
│                                                         │
│        [ ❙❙ 일시정지 ]      [ ✓ 회의 종료 ]                  │

```

| 영역 | 요소 | 유형 | 내용·규칙 |
|---|---|---|---|
| 상단 | 뒤로 가기 | 아이콘 버튼 | 녹음 시작 전에만 표시 ("회의 준비로 돌아가기") |
| | 제목 | 제목 | 회의 녹음 |

| | 녹음 상태 | 상태 배지 | 녹음 중(빨간 점 깜빡임) / 일시정지됨 / 녹음이 종료되었습니다 |

| | 입력 파형 | 시각 요소 | 입력 레벨 반영. 스크린리더용 "마이크 입력 레벨 n%" |
| | 상태 문구 | 텍스트 | 마이크를 확인하고 있습니다 / 사용할 수 없습니다 / 입력 대기 중 / 입력이 감지되었습니다 |

| | 처리 시작 재시도 | 보조 버튼 | 실패 시 |
| 행동 버튼 | 녹음 시작 | 주 버튼 | 시작 전 |
| | 일시정지 / 녹음 재개 | 보조·주 버튼 | 녹음 중 / 일시정지 중 |

| 요소 | 내용 |

## 4. 상태별 화면

| 상태 | 표시 |
|---|---|
| 마이크 확인 중 | 시작 버튼 비활성, 확인 중 문구 |
| 마이크 사용 불가 | 오류 색 표시 + 다시 확인. **제안**: 브라우저 권한 허용 방법 안내 |
| 입력 대기 | 시작 버튼 비활성, "마이크 입력 대기 중" |
| 녹음 준비 완료 | 시작 버튼 활성 |
| 녹음 중 | 빨간 상태 + 일시정지·종료 |
| 일시정지 | 재개·종료 |
| 종료 처리 중 | 단계 문구 + 진행 막대, 버튼 숨김 |
| 업로드 실패 | 업로드 재시도 |
| 처리 시작 실패 | 처리 시작 재시도 + 새 회의·목록 버튼 |
| 브라우저 저장 실패 | "녹음 데이터를 브라우저 임시 저장소에 보관하지 못했습니다. 저장 공간이나 브라우저 상태를 확인해 주세요." 녹음 중단 |
| 세션 없음 | 안내 + 새 회의 시작 |

## 5. 리뉴얼 검토 사항

- **현행 문제 (관찰)** — 종료 버튼 라벨이 "완료"라 회의 종료 의미가 약하다. 녹음 중 업로드 상태가 보이지 않아 데이터가 안전한지 알기 어렵다.
- **제안**
  - 데스크톱에서는 가운데 큰 녹음 패널 + 우측에 회의 정보(참석자, 템플릿)를 함께 표시
  - 녹음 중 업로드 상태를 작은 표시(예: "자동 저장됨 · 12조각")로 상시 노출
  - 화면 꺼짐 방지(Wake Lock) 지원 브라우저에서 적용 검토
  - 장시간 녹음 시 경과 시간 외에 예상 처리 시간 안내 여부 검토
- **확인 필요** — D-06: 녹음을 모바일에서 주로 하는지에 따라 모바일 레이아웃 우선순위가 달라진다.
