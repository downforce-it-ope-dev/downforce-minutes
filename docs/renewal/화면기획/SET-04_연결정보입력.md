# SET-04 문서 서비스 연결 정보 입력

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-04 |
| 유형 | 페이지 (마법사 2단계, 입력 폼) |
| 경로 | `/setup/document`, `/settings/document` (변경 모드) |
| 현재 구현 | `frontend/src/DocumentSetupWizard.tsx` (서비스 선택됨 상태), `documentSetupApi.ts`, `documentConnectionStorage.ts` |
| 진입 조건 | SET-03에서 서비스 선택 |
| 연결 화면 | 서비스 선택으로 돌아가기 → SET-03 / 연결 확인 성공 → 최초: SET-05(문서 생성 자동 시작), 변경: SET-05 → SET-06 |
| 하위 팝업 | SET-04-P01 연결 방법 안내 |
| 사용 API | API-024 연결 후보 저장, API-025 읽기 전용 연결 시험, API-026 문서 구조 생성 시작, API-023 상태 |
| 현행 캡처 | [노션 설정](<../현_UI/노션 설정.png>) |

## 1. 화면 개요

선택한 문서 서비스의 접속 정보를 입력하고 연결을 확인한다. 확인에 성공하면 문서 구조 생성 단계로 넘어간다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-04-F01 | Notion 정보 입력 | 내부 연결 토큰, 부모 페이지 URL 또는 ID | 둘 다 필수. 토큰은 비밀번호 입력란 |
| SET-04-F02 | Confluence 정보 입력 | 사이트 URL, Atlassian 계정 이메일, API token, Space ID | 모두 필수 |
| SET-04-F03 | 입력 검증 | 빈 값 확인 | 입력란별 오류 + 첫 오류 입력란으로 초점 이동, 폼 오류 "필수 입력을 확인해 주세요." |
| SET-04-F04 | 연결 확인 | 후보 저장 → 읽기 전용 시험 | 인증 성공 + 부모 페이지 접근 가능해야 통과. 확인 후 입력한 자격 증명은 화면에서 지움 |
| SET-04-F05 | 자동 다음 단계 | 시험 통과 시 | 최초 연결이거나 변경 모드이면 문서 구조 생성(API-026)을 바로 시작하고 SET-05로 |
| SET-04-F06 | 동시 변경 감지 | 다른 브라우저에서 설정 변경(412) | 최신 상태를 읽고 다시 입력하도록 안내 |
| SET-04-F07 | 서비스 선택으로 돌아가기 | SET-03 | 진행 중 작업이 없을 때만 |
| SET-04-F08 | 연결 방법 안내 | SET-04-P01 | - |
| SET-04-F09 | 생성될 구조 안내 | 시험 통과 후 | "Meeting Automation 아래 Meetings, Participants, Templates 페이지를 만들고…" |

## 3. 화면 구성 요소

크기·글자·색 수치는 [스타일 방식 검토](../스타일_전환_검토.md) 7.4·8장을 따른다. 마법사 단계이므로 CMN-01 "집중 모드"(메뉴 숨김, 상단 바 제목만)로 표시한다. 단계 표시와 마법사 열 폭은 SET-03 3.1·3.2를 따른다.

### 3.1 태블릿 (기준, 600px 이상)

```
┌──────────────────────────────────────────────────────────────┐
│ 문서 서비스 연결                                                │  상단 바 64px (제목만)
├──────────────────────────────────────────────────────────────┤
│        ① 서비스 선택 ✓ ─ ② 연결 정보 ● ─ ③ 문서 생성              │  단계 표시
│        ← 서비스 선택                                            │
│        (N) Notion에 연결          [ⓘ 연결 방법 안내]             │
│        서비스 연결 정보를 입력해 주세요.                            │
│                                                              │
│        Notion 내부 연결 토큰 *                                   │
│        [••••••••••••••••••••••••••••••••••••••]  [👁]        │  입력란 52 + 아이콘 버튼 48
│        연결 확인 후 입력한 토큰은 화면에서 지우며 …                    │  도움말 caption
│        부모 페이지 URL 또는 ID *                                  │
│        [https://www.notion.so/...                     ]       │
│        예: notion.so / notion.site 주소 또는 페이지 ID              │
│                                                              │
│        [⚠ 오류 안내 (danger-soft)                       ]       │
│                                                              │
│        [                 연결 확인                    ]        │  주 버튼 lg 56
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 요소 | 유형 | 내용·규칙 | 필수 |
|---|---|---|---|---|
| 상단 바 (64px) | 제목 | 제목(h1) | 문서 서비스 연결. `headline` | - |
| 머리 | 단계 표시 | 단계 표시기 | ② 연결 정보 강조 (SET-03 3.1) | - |
| | 설명 | 텍스트 | 서비스 연결 정보를 입력해 주세요. `body`, `text-muted` | - |
| | 서비스 선택으로 돌아가기 | 링크 | ← 서비스 선택. 누르는 영역 높이 48 | - |
| | 선택 서비스 | 아이콘 + 텍스트 | Notion에 연결 / Confluence에 연결. `title` | - |
| Notion 폼 | Notion 내부 연결 토큰 | 비밀 입력 | 도움말: "연결 확인 후 입력한 토큰은 화면에서 지우며 브라우저 저장소에는 저장하지 않습니다." (아래 사실 확인 참고). 입력란 48/52, 글자 16px, 보기 토글 아이콘 버튼 48(제안) | 필수 |
| | 부모 페이지 URL 또는 ID | 텍스트 입력 | notion.so / notion.site 주소 또는 ID. 입력란 48/52, 글자 16px. ID도 받으므로 `type=url`(형식 검사로 ID를 막음) 대신 `inputmode=url`로 URL 키보드만 연다(제안). 허용 형식 예시를 도움말(`caption`)로 표시(5장 제안) | 필수 |
| Confluence 폼 | Confluence 사이트 URL | URL 입력 | placeholder `https://example.atlassian.net`. 입력란 48/52, 글자 16px, `type=url`로 URL 키보드 | 필수 |
| | Atlassian 계정 이메일 | 이메일 입력 | 입력란 48/52, 글자 16px, `type=email`, `autocomplete=email`로 이메일 키보드 | 필수 |
| | Atlassian API token | 비밀 입력 | 입력란 48/52, 글자 16px, 보기 토글 아이콘 버튼 48(제안) | 필수 |
| | Space ID | 텍스트 입력 | 입력란 48/52, 글자 16px | 필수 |
| 실행 | 연결 확인 | 주 버튼 `lg` 56 | "연결 확인 중…" → 통과 시 "연결 확인 완료"(비활성). 색 `primary`. 태블릿은 폼 끝에 마법사 열 폭 가득 | - |
| 보조 | 연결 방법 안내 ⓘ | 보조 버튼 `md` 48 | SET-04-P01. 태블릿 가로에서는 안내를 상시 표시하므로 숨긴다(3.2) | - |
| 결과 | 생성될 구조 | 안내 카드 | 시험 통과 후. `success-soft` + 아이콘 | - |
| 오류 | 오류 문구 | 경고 텍스트 | 아래 메시지 표. 폼 오류는 `danger-soft` 안내 상자 + 아이콘, 입력란별 오류는 입력란 아래 `caption`. 첫 오류 입력란으로 초점 이동(F03) | - |

**긴 값 붙여넣기 (터치 키보드)**

- 토큰·URL은 다른 앱(Notion, Atlassian 관리 화면)에서 복사해 붙여넣는다고 본다. 입력란은 높이 48/52로 길게 눌러 붙여넣기 메뉴를 열기 쉽게 하고, 값이 길어도 한 줄 입력란에서 가로로 스크롤되게 둔다.
- 모든 입력란은 자동 대문자·자동 수정·맞춤법 검사를 끈다(제안). 토큰·ID는 대소문자와 기호가 의미를 가진다.
- 붙여넣은 값의 앞뒤 공백은 저장 전에 제거한다(제안, 현행 처리 여부 확인 필요).
- 비밀 입력란의 보기 토글(제안)로 붙여넣은 값이 맞는지 확인할 수 있게 한다. 연결 확인 후 자격 증명을 화면에서 지우는 현행 규칙(F04)은 그대로 둔다.
- 별도 "붙여넣기" 버튼은 브라우저 클립보드 읽기 권한이 필요하므로 **확인 필요**(제안: 만들지 않음).

### 3.2 태블릿 가로 (960px 이상)

폼 + 연결 방법 안내 2단을 쓴다(제안, 5장 "안내 상시 노출"). 이 폭에서는 SET-04-P01 팝업을 열지 않는다.

```
┌──────────────────────────────────────────────────────────────────────┐
│ 문서 서비스 연결                                                        │
├──────────────────────────────────────────────────────────────────────┤
│        ① 서비스 선택 ✓ ─ ② 연결 정보 ● ─ ③ 문서 생성                      │
│ ┌ 연결 정보 ─────────────────────┐ ┌ 연결 방법 안내 ────────────────────┐ │
│ │ (N) Notion에 연결             │ │ ① Notion 내부 연결 안내 ↗ 를 열어    │ │
│ │ 내부 연결 토큰 *               │ │    토큰을 준비합니다.               │ │
│ │ [•••••••••••••••••••] [👁]   │ │ ② 부모 페이지에 연결을 추가하고       │ │
│ │ 부모 페이지 URL 또는 ID *       │ │    읽기·콘텐츠 추가·수정 권한 허용    │ │
│ │ [https://...              ]  │ │ ③ 부모 페이지 URL 또는 ID 확인       │ │
│ │                              │ │                                │ │
│ │ [        연결 확인        ]   │ │ 먼저 서비스 연결을 읽기 전용으로 …     │ │
│ └──────────────────────────────┘ └────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

| 영역 | 내용·규칙 |
|---|---|
| 왼쪽 폼 | 3.1과 같은 입력란·버튼. "연결 방법 안내 ⓘ" 버튼은 숨긴다 |
| 오른쪽 안내 | SET-04-P01 내용을 카드(`bg-subtle` 면 또는 테두리 카드, `radius-lg`, 안쪽 여백 24)로 상시 표시. 단계 번호 + `body` 글자. 외부 링크는 누르는 영역 높이 48. 폼을 스크롤해도 안내가 보이도록 위쪽 고정(sticky)을 제안 |
| 폭 배분 | **확인 필요** — 8장에 2단 비율 정의가 없다. 제안: 폼 3 : 안내 2, 본문 최대 폭 1040px 안에서 가운데 정렬 |

### 3.3 휴대폰 (600px 미만)

- 1단, 좌우 여백 16px. 상단 바 56px(제목만), 하단 탭 바 없음(집중 모드). 단계 표시는 "2/3 연결 정보" 형태.
- 입력란 높이 48, 글자 16px(Safari 자동 확대 방지).
- "연결 확인"은 주 버튼 `lg` 56, 화면 폭 가득으로 하단에 고정하고 하단 안전 영역만큼 띄운다.
- `short`(높이 560px 이하, 키보드 열림): 상단 바·단계 표시·여백을 줄이고, 고정한 "연결 확인" 버튼을 폼 끝으로 옮긴다. 키보드가 열린 상태에서 긴 토큰을 붙여넣어도 초점이 간 입력란과 도움말이 키보드에 가리지 않게 스크롤한다.
- 연결 방법 안내(SET-04-P01)는 하단 시트로 연다.

### SET-04-P01 연결 방법 안내

- 형태: 휴대폰 하단 시트(최대 높이 90%, 안쪽 스크롤), 태블릿 세로 가운데 대화상자(최대 폭 560px). 태블릿 가로(960px 이상)는 팝업 대신 3.2 오른쪽 안내로 상시 표시(제안).
- 닫기 아이콘 버튼 48. 외부 링크(Notion 내부 연결 안내, Atlassian API token 안내)는 새 탭으로 열고 누르는 영역 높이 48.

| 서비스 | 안내 단계 (현행) |
|---|---|
| Notion | ① Notion 내부 연결 안내(외부 링크)를 열어 토큰을 준비 ② 부모 페이지에 연결을 추가하고 읽기·콘텐츠 추가·수정 권한 허용 ③ 부모 페이지 URL 또는 ID 확인 |
| Confluence | ① 사이트 URL 형식 `https://회사이름.atlassian.net` ② Atlassian API token 안내(외부 링크)와 운영 계정 이메일 준비 ③ Space ID와 페이지 생성 권한 확인 (Space 최상위에 생성) |
| 공통 | "먼저 서비스 연결을 읽기 전용으로 확인합니다. 다음 단계에서 문서 구조와 기본 회의록 템플릿을 생성합니다." |

## 5. 리뉴얼 검토 사항

- **사실 확인 (코드)** — 토큰 입력란 도움말은 "브라우저 저장소에는 저장하지 않습니다"라고 안내하지만, 연결 확인 성공 시 `savePendingDocumentConnection`이 토큰을 포함한 입력값을 브라우저 `localStorage`에 저장한다(`documentConnectionStorage.ts`). 화면 문구와 실제 동작이 다르므로 동작 또는 문구를 바로잡아야 한다(D-09).
- **현행 문제 (관찰)** — 오류 문구에 "Provider", "draft revision" 같은 내부 용어가 나온다. 실패 원인(토큰 오류인지, 페이지 권한 문제인지)이 구분되지 않는다.
- **제안**
  - 안내를 팝업 대신 폼 옆 단계별 가이드(이미지 포함)로 상시 노출. D-06(태블릿 기준, 결정)에 따라 태블릿 가로(960px 이상)에서만 폼 옆에 두고, 태블릿 세로·휴대폰은 팝업(대화상자·하단 시트)을 유지한다(3장)
  - 실패 원인 구분 표시: 토큰 인증 실패 / 부모 페이지를 찾을 수 없음 또는 연결 권한 없음 / 네트워크 — Backend 오류 코드(`SettingsException.invalid` 400, `DOCUMENT_FAILED` 502)를 기준으로 구분 가능 범위 확인
  - 부모 페이지 입력란에 허용 형식 예시 표시
- **확인 필요** — D-05(관리자 전용), D-09(브라우저 보관 유지 여부)
