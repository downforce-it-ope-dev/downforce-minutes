# SET-04 문서 서비스 연결 정보 입력

| 항목 | 내용 |
|---|---|
| 화면 ID | SET-04 |
| 유형 | 페이지 (마법사 2단계, 입력 폼) |
| 경로 | `/setup/document`, `/settings/document` (변경 모드) |
| 현재 구현 | `frontend/src/DocumentSetupWizard.tsx` (서비스 선택됨 상태), `documentSetupApi.ts`, `documentConnectionStorage.ts` |
| 진입 조건 | SET-03에서 서비스 선택 |
| 연결 화면 | 서비스 선택으로 돌아가기 → SET-03 / 연결 확인 성공 → 최초: SET-05(문서 생성 자동 시작), 변경: SET-05 → SET-06 |
| 하위 팝업 | SET-04-P01 연결 방법 안내 |
| 사용 API | API-024 연결 후보 저장, API-025 읽기 전용 연결 시험, API-026 문서 구조 생성 시작, API-023 상태 |
| 현행 캡처 | [노션 설정](<../현_UI/노션 설정.png>) |

## 1. 화면 개요

선택한 문서 서비스의 접속 정보를 입력하고 연결을 확인한다. 확인에 성공하면 문서 구조 생성 단계로 넘어간다.

## 2. 기능 정의

| 기능 ID | 기능 | 설명 | 처리 규칙 |
|---|---|---|---|
| SET-04-F01 | Notion 정보 입력 | 내부 연결 토큰, 부모 페이지 URL 또는 ID | 둘 다 필수. 토큰은 비밀번호 입력란 |
| SET-04-F02 | Confluence 정보 입력 | 사이트 URL, Atlassian 계정 이메일, API token, Space ID | 모두 필수 |
| SET-04-F03 | 입력 검증 | 빈 값 확인 | 입력란별 오류 + 첫 오류 입력란으로 초점 이동, 폼 오류 "필수 입력을 확인해 주세요." |
| SET-04-F04 | 연결 확인 | 후보 저장 → 읽기 전용 시험 | 인증 성공 + 부모 페이지 접근 가능해야 통과. 확인 후 입력한 자격 증명은 화면에서 지움 |
| SET-04-F05 | 자동 다음 단계 | 시험 통과 시 | 최초 연결이거나 변경 모드이면 문서 구조 생성(API-026)을 바로 시작하고 SET-05로 |
| SET-04-F06 | 동시 변경 감지 | 다른 브라우저에서 설정 변경(412) | 최신 상태를 읽고 다시 입력하도록 안내 |
| SET-04-F07 | 서비스 선택으로 돌아가기 | SET-03 | 진행 중 작업이 없을 때만 |
| SET-04-F08 | 연결 방법 안내 | SET-04-P01 | - |
| SET-04-F09 | 생성될 구조 안내 | 시험 통과 후 | "Meeting Automation 아래 Meetings, Participants, Templates 페이지를 만들고…" |

### SET-04-P01 연결 방법 안내

| 서비스 | 안내 단계 (현행) |
|---|---|
| Notion | ① Notion 내부 연결 안내(외부 링크)를 열어 토큰을 준비 ② 부모 페이지에 연결을 추가하고 읽기·콘텐츠 추가·수정 권한 허용 ③ 부모 페이지 URL 또는 ID 확인 |
| Confluence | ① 사이트 URL 형식 `https://회사이름.atlassian.net` ② Atlassian API token 안내(외부 링크)와 운영 계정 이메일 준비 ③ Space ID와 페이지 생성 권한 확인 (Space 최상위에 생성) |
| 공통 | "먼저 서비스 연결을 읽기 전용으로 확인합니다. 다음 단계에서 문서 구조와 기본 회의록 템플릿을 생성합니다." |

## 5. 리뉴얼 검토 사항

- **사실 확인 (코드)** — 토큰 입력란 도움말은 "브라우저 저장소에는 저장하지 않습니다"라고 안내하지만, 연결 확인 성공 시 `savePendingDocumentConnection`이 토큰을 포함한 입력값을 브라우저 `localStorage`에 저장한다(`documentConnectionStorage.ts`). 화면 문구와 실제 동작이 다르므로 동작 또는 문구를 바로잡아야 한다(D-09).
- **현행 문제 (관찰)** — 오류 문구에 "Provider", "draft revision" 같은 내부 용어가 나온다. 실패 원인(토큰 오류인지, 페이지 권한 문제인지)이 구분되지 않는다.
- **제안**
  - 안내를 팝업 대신 폼 옆 단계별 가이드(이미지 포함)로 상시 노출
  - 실패 원인 구분 표시: 토큰 인증 실패 / 부모 페이지를 찾을 수 없음 또는 연결 권한 없음 / 네트워크 — Backend 오류 코드(`SettingsException.invalid` 400, `DOCUMENT_FAILED` 502)를 기준으로 구분 가능 범위 확인
  - 부모 페이지 입력란에 허용 형식 예시 표시
- **확인 필요** — D-05(관리자 전용), D-09(브라우저 보관 유지 여부)
